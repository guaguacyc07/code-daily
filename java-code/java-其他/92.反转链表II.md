# 92. 反转链表 II

- **题目 : [92. 反转链表 II](https://leetcode.cn/problems/reverse-linked-list-ii/)**

> 难度: 中等
>
> 标签: 链表

## 解法一

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    // 记录翻转区间的下一个节点(right + 1)
    // 方便翻转后的尾部接上去
    ListNode tail = null;
    public ListNode reverseBetween(ListNode head, int left, int right) {
        // 哨兵节点, 用于返回结果(同时可以防止left == 1的情况)
        ListNode dummy = new ListNode(0, head);
        // 记录left的前一个节点
        ListNode p0 = dummy;
        for (int i = 1; i < left; i++) p0 = p0.next;

        // 此时p0是left位置的前一个节点(所以这里要传p0.next)
        ListNode newHead = dfs(p0.next, right - left + 1);
        // p0接上翻转后的新链表头
        p0.next = newHead;

        return dummy.next;
    }
    // 递归(num是要翻转的节点个数 right - left + 1)
    ListNode dfs(ListNode head, int num) {
        // 到达最右端返回(num == 1)
        if (num == 1) {
            // 此时head正好就是翻转区间的最后一个节点(right位置的节点)
            // 给tail赋值
            tail = head.next;
            // 并且当前节点就是反转后的新头, 向上返回
            return head;    
        }

        // 递归到最后一个节点先
        ListNode last = dfs(head.next, num - 1);

        // 开始翻转当前节点
        head.next.next = head;
        // 然后把当前节点指向tail节点(right + 1位置)
        head.next = tail;

        // 返回最后一个节点
        return last;
    }

}
```

- **时间复杂度：O(n)**

  先走 left - 1 步找到翻转区间的前一个节点，再递归翻转 right - left + 1 个节点；两段加起来不超过 n。

- **空间复杂度：O(n)**

  递归深度是 right - left + 1，最坏（翻转整条链表）是 O(n)，没有额外开数组。
