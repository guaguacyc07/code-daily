# 40. Diameter of Binary Tree

- **题目 : [543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)**

> 难度: 简单
>
> 标签: 树, 深度优先搜索, 二叉树

## 解法一

思路:

- 关键点---- **`任意一个节点，经过这个节点的最长路径 = 它的左子树最大深度 + 它的右子树最大深度`**

**AC代码:**

```java
class Solution {
    // 全局变量保存答案
    int ret = 0;
    public int diameterOfBinaryTree(TreeNode root) {
        // 任意一个节点，经过这个节点的最长路径 = 它的左子树最大深度 + 它的右子树最大深度。
        depth(root);
        return ret;
    }
    // 返回以root为节点的最大子树深度(后序遍历)
    int depth(TreeNode root) {
        if(root == null) return 0;

        // 遍历左子树
        int leftDepth = depth(root.left);
        // 遍历右子树
        int rightDepth = depth(root.right);
        // 记录全局最大路径长度
        ret = Math.max(ret, leftDepth + rightDepth);
        // 返回当前节点的最大深度 + 1
        return Math.max(leftDepth, rightDepth) + 1;
    }
}
```

- **时间复杂度：O(n)**

  每个节点只被访问一次（后序遍历一趟搞定，不需要对每个节点再单独求深度）。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h：平衡树 O(log n)，链状树最坏 O(n)。
