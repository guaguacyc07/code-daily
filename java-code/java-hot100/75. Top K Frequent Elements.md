# 75. Top K Frequent Elements

- **题目 : [347. 前 K 个高频元素](https://leetcode.cn/problems/top-k-frequent-elements/)**

> 难度: 中等
>
> 标签: 数组, 哈希表, 分治, 堆

## 解法一(大根堆)

```java
class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        // 创建大根堆, 里面放map的键值对对象, 根据val的值排序
        PriorityQueue<Map.Entry<Integer, Integer>> heap = new PriorityQueue<>(
            (a, b) -> b.getValue() - a.getValue()
        );
        
        Map<Integer, Integer> map = new HashMap<>();

        for (int i = 0; i < nums.length; i++) {
            // 如果存在于map中, 则对应的值加1
            // 否则新加这个键值对, 并且初始值为1
            map.put(nums[i], map.getOrDefault(nums[i], 0) + 1);
        }

        // 结果数组(大小为k)
        int[] ret = new int[k];

        // 把map的每个键值对都加进大根堆里
        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
            heap.offer(entry);
        }
        // 把数据依次从大根堆中取出, 然后填入数组
        for (int i = 0; i < k; i++) {
            ret[i] = heap.poll().getKey();
        }
        return ret;
    }   
}
```

- **时间复杂度：O(n + (m + k) log m)**

  统计频率 O(n)（m 是不同元素的个数）；把 m 个键值对逐个 `offer` 进堆是 O(m log m)；再弹出 k 次、每次 O(log m)。最坏 m ≈ n，也就是 O(n log n)。

- **空间复杂度：O(n)**

  哈希表和堆各存 m 项，m ≤ n。
