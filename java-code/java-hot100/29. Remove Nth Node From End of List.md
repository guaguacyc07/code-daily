# 29. Remove Nth Node From End of List

- **题目 : [19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)**

> 难度: 中等
>
> 标签: 链表, 双指针

## 解法一

**思路:**

- 这题让我有点回忆**[206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)**这道题目
- 我们可以递归, 从后往前遍历
- 递归只干一件事 -- 把当前节点的下个节点指向递归后的结果
- 如果 **当前节点就是倒数第n个，直接返回next**

**AC代码:**

```java
class Solution {
    int count = 0;
    public ListNode removeNthFromEnd(ListNode head, int n) {
        // 递归后序遍历
        if(head == null) return head;
        head.next = removeNthFromEnd(head.next, n);
        count++;
        // 当前节点就是倒数第n个，直接返回next，相当于删掉当前节点
        if(count == n){
            return head.next;
        }
        return head;
    }
}
```

- **时间复杂度：O(L)**

  递归走完整条链表一次，每个节点只处理一次（L 为链表长度）。

- **空间复杂度：O(L)**

  递归栈深度等于链表长度。
