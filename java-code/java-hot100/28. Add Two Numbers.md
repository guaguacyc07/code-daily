# 28. Add Two Numbers

- **题目 : [2. 两数相加](https://leetcode.cn/problems/add-two-numbers/)**

> 难度: 中等
>
> 标签: 递归, 链表, 数学

## 解法一

- 模拟加法就行了

- `ten`是十位的数, `digit` 是个位的数

**AC代码:**

```java
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode ans = new ListNode();
        ListNode ret = ans;
        // 记录个位
        int digit = 0;

        while(l1 != null || l2 != null || digit != 0) {
            int sum = digit;
            
            if(l1 != null) {
                sum += l1.val;
                l1 = l1.next;
            }
            if(l2 != null) {
                sum += l2.val;
                l2 = l2.next;
            }
            int ten = sum / 10;
            digit = sum % 10;

            ans.next = new ListNode(digit);   
            ans = ans.next;
            
            digit = ten;
        }
        return ret.next;
    }
}
```

- **时间复杂度：O(max(m, n))**

  两个链表各遍历一遍，取较长的那个；最后可能还多走一次处理进位。

- **空间复杂度：O(max(m, n))**

  结果本身要新建 max(m, n) + 1 个节点（不计输出的话，额外空间只有哨兵节点和几个变量，是 O(1)）。
