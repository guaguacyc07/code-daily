# 46. Flatten Binary Tree to Linked List

- **题目 : [114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)**

> 难度: 中等
>
> 标签: 栈, 树, 深度优先搜索, 链表

## 解法一

**思路:**

- **展开后的单链表应该与二叉树 [先序遍历](https://baike.baidu.com/item/先序遍历/6442839?fr=aladdin) 顺序相同**
- 那么我们可以在先序遍历的过程中构建这个链表
- 为方便, 我们创建一个辅助节点 `pre`
- 一定要**先保存原左右子树，防止被覆盖丢失**
- 这是因为我们后面处理当前节点时会让**左指针置空**
- 而我们在**左子树递归过程中`root.right`被覆盖修改**
- 所以必须先保存左右子树

**如果不保存右子树会怎么样?**

- 处理当前节点时，`pre = root`（pre 指向当前节点）
- 进入左子树递归后，执行 `pre.right = root`（此时 root 是左孩子），等价于 **把父节点的 `right` 指针直接改成了左孩子**
- 父节点原本的右子树，没有任何变量引用它，就此永久丢失

**AC代码:**

```java
class Solution {
    // 定义一个辅助节点
    TreeNode pre = new TreeNode();
    public void flatten(TreeNode root) {
        // 先序 根-左-右
        if (root == null) return;
        // 先保存原左右子树，防止被覆盖丢失
        TreeNode left = root.left;
        TreeNode right = root.right;

        // 处理当前节点
        pre.right = root;
        pre = root;
        // 左指针置空
        root.left = null; 

        // 递归左子树
        flatten(left);
        // 递归右子树
        flatten(right);
    }
}
```

- **时间复杂度：O(n)**

  每个节点只被拼接一次。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h（平衡树 O(log n)，链状树 O(n)）。

## 解法二

**反先序遍历**

按「右 - 左 - 根」的顺序递归，从后往前拼接链表，天然不会覆盖右子树：

```java
class Solution {
    // 辅助节点, 用来记录已经构建好的那一段链表的头部
    TreeNode tail = null;
    public void flatten(TreeNode root) {
        if (root == null) return;
        // 先递归右子树，再递归左子树
        flatten(root.right);
        flatten(root.left);
        // 当前节点拼接已处理好的链表
        root.right = tail;
        root.left = null;
        tail = root;
    }
}
```

- **时间复杂度：O(n)**

  每个节点只被访问一次。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h。两种解法都是 O(n) 时间 / O(h) 空间；想做到 O(1) 额外空间，可以用 Morris 式的迭代写法（每次把"左子树最右节点"接到右子树上）。
