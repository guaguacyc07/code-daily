# 81. Climbing Stairs

- **题目 : [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)**

> 难度: 简单
>
> 标签: 记忆化搜索, 数学, 动态规划

## 解法一

```java
class Solution {
    public int climbStairs(int n) {
        if (n == 1) return 1;
        if (n == 2) return 2;
        // 状态转移方程
        // dp[n]表示当前走到n有多少种方法
        // dp[n] = dp[n - 1] + dp[n - 2]
        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = 1;
        dp[2] = 2;

        // 从索引3开始
        for (int i = 3; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2];
        } 
        return dp[n];
    }
}
```

- **时间复杂度：O(n)**

  从 3 递推到 n，线性。

- **空间复杂度：O(n)**

  `dp` 数组开了 n + 1 个位置。其实每项只依赖前两项，用两个变量滚动就能压到 O(1)，这里先用最直观的数组写法。
