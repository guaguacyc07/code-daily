# 60. Word Search

- **题目 : [79. 单词搜索](https://leetcode.cn/problems/word-search/)**

> 难度: 中等
>
> 标签: 深度优先搜索, 数组, 字符串, 回溯

## 解法一

> 太慢了, 940ms
>
> 进行优化

```java
class Solution {
    // 记录当前位置是否被遍历过
    boolean[][] flag;
    public boolean exist(char[][] board, String word) {
        flag = new boolean[board.length][board[0].length];
        StringBuilder ans =  new StringBuilder();
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                // 先把当前节点加进去
                ans.append(board[i][j]);
                flag[i][j] = true;
                // 递归四个方向
                if (dfs(board, word, ans, i, j)) return true;
                // 回溯
                ans.deleteCharAt(ans.length() - 1);
                flag[i][j] = false;
            }
        }
        return false;
    }
    boolean dfs(char[][] board, String word ,StringBuilder ans, int x, int y) {
        // 出口(当ans长度与word相同时)
        if (ans.length() == word.length()) {
            return ans.toString().equals(word);
        }

        // 选上边
        if (inArea(board, x - 1, y) && !flag[x - 1][y]) {
            ans.append(board[x - 1][y]);
            flag[x - 1][y] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, ans, x - 1, y)) {
                return true;
            }
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
            flag[x - 1][y] = false;
        }
        // 选左边
        if (inArea(board, x, y - 1) && !flag[x][y - 1]) {
            ans.append(board[x][y - 1]);
            flag[x][y - 1] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, ans, x, y - 1)) {
                return true;
            }
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
            flag[x][y - 1] = false;
        }
        // 选下边
        if (inArea(board, x + 1, y) && !flag[x + 1][y]) {
            ans.append(board[x + 1][y]);
            flag[x + 1][y] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, ans, x + 1, y)) {
                return true;
            }
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
            flag[x + 1][y] = false;
        }
        // 选右边
        if (inArea(board, x, y + 1) && !flag[x][y + 1]) {
            ans.append(board[x][y + 1]);
            flag[x][y + 1] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, ans, x, y + 1)) {
                return true;
            }
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
            flag[x][y + 1] = false;
        }
        return false;
    }

    // 判断是否在网格范围内
    boolean inArea(char[][] board, int x, int y) {
        return 0 <= x && x < board.length && 0 <= y && y < board[0].length;
    }
}
```



- **时间复杂度：O(m·n·4^L · L)**

  m、n 为网格的行列数，L 为 word 的长度。外层要枚举 m·n 个起点，每个起点最坏要尝试深度 L 的 4 叉搜索树，也就是 4^L 条路径；而每个叶子还要把长度 L 的 `ans` 拼成字符串再和 word 整个比较，多一层 O(L)。所以这一版会慢（实测 940ms）。

- **空间复杂度：O(m·n + L)**

  `flag` 数组 O(m·n)，递归深度和 `StringBuilder` 长度都是 O(L)。不计返回值。

## 优化一

把StringBuilder换成了直接看索引

```java
class Solution {
    // 记录当前位置是否被遍历过
    boolean[][] flag;
    public boolean exist(char[][] board, String word) {
        int m = board.length;
        int n = board[0].length;
        // 剪枝1:单词长度超过网格总格子数,直接不可能存在路径
        if (word.length() > m * n) return false;

        flag = new boolean[m][n];
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                // 先把当前节点加进去
                flag[i][j] = true;
                // 递归四个方向
                if (dfs(board, word, 0, i, j)) return true;
                // 回溯
                flag[i][j] = false;
            }
        }
        return false;
    }
    boolean dfs(char[][] board, String word ,int curIdx, int x, int y) {
        // 当前格子字符与目标位不匹配,直接剪枝返回
        if (board[x][y] != word.charAt(curIdx)) {
            return false;
        }
        // 终止条件:已经匹配到最后一个字符,匹配成功
        if (curIdx == word.length() - 1) {
            return true;
        }

        // 选上边
        if (inArea(board, x - 1, y) && !flag[x - 1][y]) {
            flag[x - 1][y] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, curIdx + 1, x - 1, y)) {
                return true;
            }
            // 回溯
            flag[x - 1][y] = false;
        }
        // 选左边
        if (inArea(board, x, y - 1) && !flag[x][y - 1]) {
            flag[x][y - 1] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, curIdx + 1, x, y - 1)) {
                return true;
            }
            // 回溯
            flag[x][y - 1] = false;
        }
        // 选下边
        if (inArea(board, x + 1, y) && !flag[x + 1][y]) {
            flag[x + 1][y] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, curIdx + 1, x + 1, y)) {
                return true;
            }
            // 回溯
            flag[x + 1][y] = false;
        }
        // 选右边
        if (inArea(board, x, y + 1) && !flag[x][y + 1]) {
            flag[x][y + 1] = true;
            // 接收返回值，找到则直接向上返回true
            if (dfs(board, word, curIdx + 1, x, y + 1)) {
                return true;
            }
            // 回溯
            flag[x][y + 1] = false;
        }
        return false;
    }

    // 判断是否在网格范围内
    boolean inArea(char[][] board, int x, int y) {
        return 0 <= x && x < board.length && 0 <= y && y < board[0].length;
    }
}
```

- **时间复杂度：O(m·n·4^L)**

  同样是枚举起点 + 4 方向搜索，但每个节点只做一次 `board[x][y] != word.charAt(curIdx)` 的比较，O(1)，不用拼串也不用整串比较；字符不匹配就立刻返回，所以没有上一版的 O(L) 因子。

- **空间复杂度：O(m·n + L)**

  `flag` 数组 O(m·n)，递归深度最多 L 层（这一版不再用 `StringBuilder`）。
