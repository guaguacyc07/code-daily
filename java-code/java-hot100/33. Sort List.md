# 33. Sort List

- **题目 : [148. 排序链表](https://leetcode.cn/problems/sort-list/)**

> 难度: 中等
>
> 标签: 链表, 双指针, 分治, 排序

## 解法一(歪门邪道)

直接把链表的值全部拿出来放到数组里面

然后给数组排序后再遍历链表赋值回去

> 虽然可以AC, 但还是老老实实学下归并吧

**AC代码:**

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if(head == null || head.next == null) return head;

        ListNode cur = head;
        
        List<Integer> list = new ArrayList<>();
        while(cur != null) {
            list.add(cur.val);
            cur = cur.next;
        }
        
        Collections.sort(list);

        cur = head;
        int idx = 0;
        while(cur != null) {
            cur.val = list.get(idx);
            idx++;
            cur = cur.next;
        }
        return head;
    }
}
```

- **时间复杂度：O(n log n)**

  主要是 `Collections.sort` 的排序开销，两趟遍历是 O(n)。

- **空间复杂度：O(n)**

  额外开了一个装 n 个元素的数组（`ArrayList`），所以不符合题目"常数级额外空间"的进阶要求。

## 解法二

**归并排序**

首先务必复习下 **[21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)** 以及 **用快慢指针找到链表中点**

其次对于 **递归** , 我个人认为, 不要在意他的过程, 你只管结果就行

比如这里 , 我们只需要知道

 **`sortList(ListNode head)`** 这个方法能够把以head为开头的链表全部排序好, 并且返回排序好后的头节点就行

然后你就可以开始用递归了...

**AC代码:**

```java
class Solution {
    public ListNode sortList(ListNode head) {
        if(head == null || head.next == null) return head;
                
        ListNode mid = findmid(head);
        ListNode nxtHead = mid.next;
        // 这里要分离左右链表
        mid.next = null;
        ListNode leftHead = sortList(head);
        ListNode rightHead = sortList(nxtHead);
        
        ListNode ret = merge(leftHead, rightHead);
        
        return ret;
    }
    // 如果是偶数个，返回左半部分右边界
    ListNode findmid(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;
        
        while(fast.next != null && fast.next.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }
        return slow;
    }
    
    // 合并有序链表
    ListNode merge(ListNode list1, ListNode list2) {
        ListNode ans = new ListNode(-100001);
        ListNode ret = ans;
        
        while(list1 != null && list2 != null) {
            if(list1.val <= list2.val) {
                ans.next = list1;
                list1 = list1.next;
            } else {
                ans.next = list2;
                list2 = list2.next;
            }
            ans = ans.next;
        }
        if(list1 == null) ans.next = list2;
        if(list2 == null) ans.next = list1;
        
        return ret.next;
    }
}
```

- **时间复杂度：O(n log n)**

  每次二分把链表拆成两半（共 log n 层），每层合并所有节点合计 O(n)。

- **空间复杂度：O(log n)**

  只有递归栈开销（链表归并不像数组归并那样需要 O(n) 的临时数组）。
