# 73. Largest Rectangle in Histogram

- **题目 : [84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)**

> 难度: 困难
>
> 标签: 栈, 数组, 单调栈

## 解法一

```java
class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        // 1.第一遍遍历: 求每个柱子的左边界left[i]
        int[] left = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();
        for (int i = 0; i < n; i++) {
            // 遍历得到当前的高度
            int h = heights[i];
            // 如果栈里有元素, 且比当前h高, 那么就出栈
            while (!stack.isEmpty() && heights[stack.peek()] >= h) stack.pop();
            // 如果此时栈空了, 说明左边没有比当前高度h低的, 左边都比当前高度高
            // 那么直接返回 -1, 否则返回栈顶
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            // 最后把当前高度的索引进栈
            stack.push(i);
        }
        // 2.第二遍遍历: 求每个柱子的右边界right[i]
        int[] right = new int[n];
        // 先把栈清空, 防止第一次遍历的残留数据影响到第二次遍历
        stack.clear();
        // 从右往左
        for (int i = n - 1; i >= 0; i--) {
            int h = heights[i];
            // 此处同理
            while (!stack.isEmpty() && heights[stack.peek()] >= h) stack.pop();
            right[i] = stack.isEmpty() ? n : stack.peek();
            stack.push(i);
        }
        // 3.第三遍遍历: 计算每个柱子的最大矩形面积
        int ret = 0;
        for (int i = 0; i < n; i++) {
            // 左右边界本身是更矮的柱子, 不属于有效宽度, 所以减 1
            ret = Math.max(ret, heights[i] * (right[i] - left[i] - 1));
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  两趟单调栈，每个下标在每趟里最多入栈、出栈各一次，第三趟是线性扫描；总共 O(n)。

- **空间复杂度：O(n)**

  `left`、`right` 两个数组加一个单调栈，都是 O(n)。
