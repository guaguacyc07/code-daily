# 48. Path Sum III

- **题目 : [437. 路径总和 III](https://leetcode.cn/problems/path-sum-iii/)**

> 难度: 中等
>
> 标签: 树, 深度优先搜索, 二叉树

## 解法一

思路:

- 看注释

**AC代码:**

```java
class Solution {
    public int pathSum(TreeNode root, long targetSum) {
        // 空树不存在任何路径, 直接返回 0
        if (root == null) return 0;

        // 1. 以当前节点 root 作为路径起点, 能凑出 targetSum 的路径数量
        int ret = rootSum(root, targetSum);
        // 2. 递归左子树: 把左子树的每个节点都当作新起点, 累加符合条件的路径数
        ret += pathSum(root.left, targetSum);
        // 3. 递归右子树: 把右子树的每个节点都当作新起点, 累加符合条件的路径数
        ret += pathSum(root.right, targetSum);

        // 返回以当前节点为根的整棵子树中，所有符合条件的路径总数
        return ret;
    }

    /**
     * 辅助递归函数:计算[以当前节点 root 为起点], 向下延伸的路径中, 和为 targetSum 的路径数量
     */
    int rootSum(TreeNode root, long targetSum) {
        int ret = 0;
        // 节点为空, 无法形成路径, 直接返回 0
        if (root == null) return 0;

        // 如果当前节点的值恰好等于剩余目标和, 说明找到一条有效路径, 计数 +1
        if (targetSum == root.val) ret++;

        // 递归左子节点:目标和减去当前节点值, 继续向下延伸路径
        ret += rootSum(root.left, targetSum - root.val);
        // 递归右子节点:目标和减去当前节点值, 继续向下延伸路径
        ret += rootSum(root.right, targetSum - root.val);

        // 返回以当前节点为起点的所有符合条件的路径总数
        return ret;
    }
}
```

- **时间复杂度：O(n²)**

  `pathSum` 会把每个节点都当成起点，而每次 `rootSum` 又要从该起点向下扫一遍；最坏（链状树）是 n + (n-1) + … = O(n²)，平衡树约 O(n·log n)。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h（`rootSum` 与 `pathSum` 的递归不会叠加成更高量级）。

## 解法二

```java
class Solution {
    // 前缀和优化
    // Map含义: key = 从根节点到当前路径上某节点的前缀和; value = 该前缀和出现的次数
    Map<Long, Integer> prefix = new HashMap<>();
    
    /**
     * 主函数: 统计二叉树中路径和等于 targetSum 的路径总数
     * 路径规则: 自上而下连续，无需从根开始、无需到叶子结束
     * @param root      二叉树根节点
     * @param targetSum 目标路径和
     * @return 符合条件的路径总数
     */
    public int pathSum(TreeNode root, long targetSum) {
        // 初始化：前缀和为 0 的路径有 1 条(代表空路径, 用于匹配从根节点开始刚好等于 targetSum 的情况)
        prefix.put(0L, 1);
        // dfs, 传入根节点, 初始前缀和0, 目标和
        return dfs(root, 0, targetSum);
    }

    /**
     * 深度优先遍历 + 前缀和回溯
     * @param root      当前遍历节点
     * @param cur       从根节点到「当前节点的父节点」的前缀和
     * @param targetSum 目标路径和
     * @return 以当前节点为根的子树中，符合条件的路径总数
     */
    int dfs(TreeNode root, long cur, long targetSum) {
        // 空节点无路径, 返回 0
        if (root == null) return 0;

        // 更新当前前缀和: 加上当前节点的值，得到根到当前节点的完整前缀和
        cur += root.val;

        // 核心逻辑: 如果存在[之前的前缀和 = 当前前缀和 - 目标和]
        // 说明从那个前缀和对应的节点之后, 到当前节点为止, 这段路径的和恰好等于 targetSum
        // 有多少个这样的前缀和, 就新增多少条有效路径
        int ret = prefix.getOrDefault(cur - targetSum, 0);

        // 将当前前缀和加入哈希表, 计数 +1, 供当前节点的子树使用
        prefix.put(cur, prefix.getOrDefault(cur, 0) + 1);

        // 递归遍历左子树, 累加左子树中的有效路径数
        ret += dfs(root.left, cur, targetSum);
        // 递归遍历右子树, 累加右子树中的有效路径数
        ret += dfs(root.right, cur, targetSum);

        // 回溯: 当前节点的左右子树都遍历完后, 将当前前缀和的计数 -1
        // 原因: 路径必须是自上而下的单一路径, 不能跨分支;
        // 回到父节点后, 当前分支的前缀和不能影响父节点的其他分支
        prefix.put(cur, prefix.getOrDefault(cur, 0) - 1);

        // 返回当前子树中所有符合条件的路径总数
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  每个节点只被访问一次，哈希表查询与更新都是 O(1)。

- **空间复杂度：O(h)**

  哈希表最多同时存「根到当前节点」这一条路径上的前缀和，即 O(h)；外加递归栈 O(h)。
