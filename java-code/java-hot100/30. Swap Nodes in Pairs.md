# 30. Swap Nodes in Pairs

- **题目 : [24. 两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)**

> 难度: 中等
>
> 标签: 递归, 链表

## 解法一

**思路:**

<img src="./img/30.%20Swap%20Nodes%20in%20Pairs.assets/image-20260921211248917.png" alt="image-20260921211248917" style="zoom:67%;" />

- 可以用一个 `pre` 节点去指向要交换的两个节点的前面那个位置, 如图 `黑色节点`

- 然后要保证 `pre` 后面至少有两个节点才能进行 交换 操作

**AC代码:**

```java
class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode pre = new ListNode(-1);
        ListNode ret = pre;
        pre.next = head;

        // 后面至少有两个节点才交换
        while(pre.next != null && pre.next.next != null) {
            ListNode fir = pre.next;
            ListNode sec = pre.next.next;

            // 交换节点
            fir.next = sec.next;
            sec.next = fir;
            pre.next = sec;

            // 移动pre到要交换的俩个节点前面的那个节点
            pre = fir;
        }
        return ret.next;
    }
}
```

- **时间复杂度：O(n)**

  每两个节点做一次常数次指针交换，共 n/2 组，整体一趟遍历。

- **空间复杂度：O(1)**

  只用了哨兵节点 `pre`、`ret` 和两个临时指针，节点本身原地重连。
