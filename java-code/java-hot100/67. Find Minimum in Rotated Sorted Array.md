# 67. Find Minimum in Rotated Sorted Array

- **题目 : [153. 寻找旋转排序数组中的最小值](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)**

> 难度: 中等
>
> 标签: 数组, 二分查找

## 解法一

最直观的一个特性就是:

左半部分一定大于右半部分全部

`[4,5,6,7,0,1,2]`

所以**如果当前取到的mid小于最右边的值, 那么说明在左半部分**

```java
class Solution {
    public int findMin(int[] nums) {
        int n = nums.length;
        int left = 0;
        int right = n - 1;
        // 二分
        while(left < right) {
            int mid = (left + right) >> 1;
            // 如果当前取到的mid小于最右边的值
            // 那么说明在左半部分
            if(nums[mid] <= nums[n - 1]) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        // 这里因为循环条件是left == right
        // 所以返回left的值亦或是right的值没有区别
        return nums[left];
    }
}
```

- **时间复杂度：O(log n)**

  标准二分，每次砍掉一半区间。

- **空间复杂度：O(1)**

  只用了 left、right、mid 三个变量。
