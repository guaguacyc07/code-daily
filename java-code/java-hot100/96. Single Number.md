# 96. Single Number

- **题目 : [136. 只出现一次的数字](https://leetcode.cn/problems/single-number/)**

> 难度: 简单
>
> 标签: 位运算, 数组

## 解法一

```java
class Solution {
    // 找出数组中只出现一次的数字(其余数字均出现两次)
    public int singleNumber(int[] nums) {
        int single = 0;
        // 异或特性: 相同数异或为0, 0异或任意数等于该数本身
        // 成对数字相互抵消, 最终剩下唯一出现一次的数
        for (int num : nums) {
            single ^= num;
        }
        return single;
    }
}
```

- **时间复杂度：O(n)**

  只遍历一遍数组，异或是 O(1) 操作。

- **空间复杂度：O(1)**

  只用了一个 `single` 变量，没有额外开数组或哈希表。
