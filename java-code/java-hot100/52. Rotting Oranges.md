# 52. Rotting Oranges

- **题目 : [994. 腐烂的橘子](https://leetcode.cn/problems/rotting-oranges/)**

> 难度: 中等
>
> 标签: 广度优先搜索, 数组, 矩阵

## 解法一

思路:

- 这题只能用bfs来做, 因为他是一层一层向外污染,每次污染要记录时间

**AC代码:**

```java
// 定义一个坐标类, 方便存于队列中
class Point {
    int x;
    int y;

    public Point() {}
    public Point(int x, int y) {
        this.x = x;
        this.y = y;
    }
}

class Solution {
    // 记录最小分钟数
    int ans = 0;
    public int orangesRotting(int[][] grid) {
        // 开始污染
        bfs(grid);
        // 遍历看看有没有未被污染的, 如果有返回-1(说明不可能)
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if(grid[i][j] == 1) return -1;
            }
        }
        return ans;
    }
    // 每分钟扩散一次污染, 所以只能用bfs
    void bfs(int[][] grid) {
        // 定义队列用于bfs
        // 队列里面存被污染的坐标
        Queue<Point> q = new ArrayDeque<>();

        // 遍历grid数组, 把腐烂的橘子的坐标存入队列中
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                if(grid[i][j] == 2) q.offer(new Point(i, j));
            }
        }

        // 开始bfs污染
        while (!q.isEmpty()) {
            // 获取当前层节点数
            int size = q.size();
            // 判断是否污染成功(只污染一个也算成功)
            boolean flag = false;

            for (int i = 0; i < size; i++) {
                // 从队列中取出坐标对象
                Point point = q.poll();
                // 取出坐标
                int x = point.x;
                int y = point.y;
                // 向当前坐标上边污染(污染前先判断是否在合理坐标范围内, 下面同理)
                if (inArea(grid, x - 1, y)) {
                    if (grid[x - 1][y] == 1) {
                        grid[x - 1][y] = 2;
                        // 把新的腐烂橘子加入队列(下面同理)
                        q.offer(new Point(x - 1, y));
                        flag = true;
                    }
                }
                // 向当前坐标左边污染
                if (inArea(grid, x, y - 1)) {
                    if (grid[x][y - 1] == 1) {
                        grid[x][y - 1] = 2;
                        q.offer(new Point(x, y - 1));
                        flag = true;
                    } 
                }
                // 向当前坐标下边污染
                if (inArea(grid, x + 1, y)) {
                    if (grid[x + 1][y] == 1) {
                        grid[x + 1][y] = 2;
                        q.offer(new Point(x + 1, y));
                        flag = true;
                    }
                }
                // 向当前坐标右边污染
                if (inArea(grid, x, y + 1)) {
                    if (grid[x][y + 1] == 1) {
                        grid[x][y + 1] = 2;
                        q.offer(new Point(x, y + 1));
                        flag = true;
                    }
                }
            }
            // 如果污染成功, 时间加一分钟
            if(flag) ans++;
        }
    }

    // 判断是否在合理的坐标范围内
    boolean inArea(int[][] grid, int x, int y) {
        return 0 <= x && x < grid.length && 0 <= y && y < grid[0].length;
    }
}
```

- **时间复杂度：O(m·n)**

  每个橘子最多入队、出队一次；最后再扫一遍网格检查有没有漏网的，也是 O(m·n)。

- **空间复杂度：O(m·n)**

  队列最多同时装下所有腐烂橘子（最坏情况整片网格都是 2，即 m·n 个坐标对象）。
