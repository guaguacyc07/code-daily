# 53. Course Schedule

- **题目 : [207. 课程表](https://leetcode.cn/problems/course-schedule/)**

> 难度: 中等
>
> 标签: 深度优先搜索, 广度优先搜索, 图

## 解法一

[图-拓扑排序](https://www.bilibili.com/video/BV1XV411X7T7/?spm_id_from=333.337.search-card.all.click&vd_source=b66e702d0f4d3341f09a3739e5b369e4)

写前要先了解 **拓扑排序**

这道题的本质就是: 给你一个有向图，判断图中是否有环

```java
class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // 入度数组: inDegree[i] 表示课程 i 的入度(有多少门先修课)
        int[] inDegree = new int[numCourses];

        // 邻接表: 存图的结构
        // list.get(i) 表示: 学完课程 i 之后, 可以解锁哪些后续课程
        List<List<Integer>> list = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            list.add(new ArrayList<>());
        }

        // 构建图: 填充入度数组 + 邻接表
        for (int[] prerequisite : prerequisites) {
            // 当前课程
            int course = prerequisite[0]; 
            // 当前课程的先修课
            int precourse = prerequisite[1];

            // 当前课程的入度 +1 (多了一门先修课)
            inDegree[course]++;
            // 先修课的后续列表里面加上当前课程
            list.get(precourse).add(course);
        }

        // 初始化队列: 放入所有[入门课](初始时入度为0的课)
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if(inDegree[i] == 0) queue.offer(i);
        }

        // 记录已经能学完的课程数量
        int count = 0;
        // 拓扑排序(bfs)
        while (!queue.isEmpty()) {
            // 在队列中的都是当前入度为0的课(意味着当前可以学), 取出课程
            int selectedCourse = queue.poll();
            // 学完了, 计数 +1
            count++;

            // 拿到这门课的后续所有课程
            List<Integer> nextCourses = list.get(selectedCourse);

            // 遍历
            for (int nextCourse : nextCourses) {
                // 因为当前这门课学完了, 所以后续的课入度要 -1
                inDegree[nextCourse]--;
                // 如果入度变为了0, 那么说明全部先修课已经学完了, 可以加入队列去学习了
                if (inDegree[nextCourse] == 0) {
                    queue.offer(nextCourse);
                }
            }
        }
        // 最终判断
        // 如果 count 等于总课程数: 所有课都能被合法排序 (无环 -- true)
        // 如果 count 小于总课程数: 剩下的课入度永远不为 0 (说明存在环 → false)
        return count == numCourses;
    }
}
```

- **时间复杂度：O(V + E)**

  V = `numCourses`，E = `prerequisites.length`。建图遍历一遍 E；拓扑排序中每个课程入队、出队各一次，每条边也只被访问一次。

- **空间复杂度：O(V + E)**

  入度数组 O(V)、邻接表 O(V + E)、队列最多 O(V)。
