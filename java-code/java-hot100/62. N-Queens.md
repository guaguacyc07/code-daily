# 62. N-Queens

- **题目 : [51. N 皇后](https://leetcode.cn/problems/n-queens/)**

> 难度: 困难
>
> 标签: 数组, 回溯

## 解法一

<img src="./img/62. N-Queens.assets/image-20261025200850752.png" alt="image-20261025200850752" style="zoom:50%;" />

我们可以发现

对于 `i+j` 的值, 可以判断是否在同一个 '/' 斜线上

对于 `i-j` 的值, 可以判断是否在同一个 '\\' 斜线上

```java
class Solution {
    List<List<String>> ret = new ArrayList<>();
    // 1. 存放列的组合
    Set<Integer> colSet = new HashSet<>(); 
    // 2. 存放左下到右上斜线的组合('/')
    Set<Integer> addSet = new HashSet<>(); 
    // 3. 存放左上到右下斜线的组合('\')
    Set<Integer> subSet = new HashSet<>();    
    char[][] arr;
    public List<List<String>> solveNQueens(int n) {
        // 初始化 n×n 棋盘，所有位置默认填充空位 '.'
        arr = new char[n][n];
        for(int i = 0; i < n; i++) {
             Arrays.fill(arr[i], '.');
        }
        dfs(n, 0, new ArrayList<>());
        return ret;
    }
    // row: 当前在递归第几行
    void dfs(int n, int row, List<String> ans) {
        // 递归出口(当行组合 = '/'组合 = '\'组合时)
        if (colSet.size() == n && addSet.size() == n && subSet.size() == n) {
            ret.add(new ArrayList<>(ans));
            return;
        }

        // 开始遍历当前行每一列
        for (int i = 0; i < n; i++) {
            // 如果列不冲突
            if (colSet.add(i)) {
                // 如果'/'斜线不冲突
                if (addSet.add(row + i)) {
                    // 如果'\'斜线不冲突
                    if (subSet.add(row - i)) {
                        arr[row][i] = 'Q';
                        // 当前行转字符串, 加入路径
                        ans.add(new String(arr[row]));
                        // 递归处理下一行
                        dfs(n, row + 1, ans);
                        // 回溯
                        arr[row][i] = '.';
                        ans.remove(ans.size() - 1);
                        subSet.remove(row - i);
                    }   
                    addSet.remove(row + i);                
                }
                colSet.remove(i);
            }  
        }
    }
}
```

- **时间复杂度：O(n!)**

  每行放一个皇后、列不能重复，搜索树的路径最多 n! 条；两条斜线的剪枝会让实际搜索量远小于这个数。每个合法棋盘还要把 n 行转成字符串，O(n^2)。

- **空间复杂度：O(n^2)**

  棋盘 `arr` 是 n×n；三个 Set、递归栈和当前路径都是 O(n)。不计返回的结果集。
