# 80. Partition Labels

- **题目 : [763. 划分字母区间](https://leetcode.cn/problems/partition-labels/)**

> 难度: 中等
>
> 标签: 贪心, 哈希表, 双指针

## 解法一

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        List<Integer> ret = new ArrayList<>();

        // 贪心
        // 找到第一个字母在字符串s中最后的位置last
        // 然后在0 - last中继续找下一个字母在字符串s中最后的位置newLast
        // 判断: 如果last < newLast, 那就更新last, 然后重复上述操作
        // 总会有一个last不会再更新, 那这里就是切割点
        // 所以个数是 last - start + 1
        Map<Character, Integer> map = new HashMap<>();
        // 用map存储每个字母的last
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            map.put(ch, i);
        }
        
        // 记录每一段的起点
        int start = 0;
        // 记录每一段的终点
        int last = 0;
        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            last = Math.max(last, map.get(ch));

            if (last == i) {
                ret.add(last - start + 1);
                start = i + 1;
            }
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  先扫一遍记录每个字母最后出现的位置，再扫一遍划分区间。

- **空间复杂度：O(1)**

  哈希表最多存 26 个字母，和 n 无关。
