```java
class Solution {
    // 结果集
    List<List<Integer>> ret = new ArrayList<>();
    public List<List<Integer>> subsets(int[] nums) {
        dfs(nums, 0, new ArrayList<>());
        return ret;
    }
    // dfs
    void dfs(int[] nums, int idx, List<Integer> ans) {
        // 递归出口
        if (idx == nums.length) {
            ret.add(new ArrayList<>(ans));
            return;
        }

        // 对于每个数, 都有选或者不选俩种选择
        // 1. 如果我们不选, 那我们直接跳过, 递归到idx + 1
        dfs(nums, idx + 1, ans);

        // 2. 如果我们选, 那就加进ans
        ans.add(nums[idx]);
        // 继续递归下一个数
        dfs(nums, idx + 1, ans);
        // 回溯
        ans.remove(ans.size() - 1);
    }
}
```

- **时间复杂度：O(n × 2^n)**

  每个元素都是"选或不选"两种，一共 2^n 个叶子（也就是 2^n 个子集）；每个叶子要把长度不超过 n 的 `ans` 拷贝一份存进结果，这一步 O(n)；递归树内部节点总数也是 O(2^n) 量级。合起来是 O(n × 2^n)。

- **空间复杂度：O(n)**

  不计返回的结果集：递归深度最多 n 层，当前路径 `ans` 长度不超过 n。如果把 2^n 个子集的结果集也算进去，就是 O(n × 2^n)。
