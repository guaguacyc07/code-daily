# 50. Binary Tree Maximum Path Sum

- **题目 : [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)**

> 难度: 困难
>
> 标签: 树, 深度优先搜索, 动态规划

## 解法一

注意点:

- 记录全局最大路径和的时候, 要把当前节点当作路径中的一员, 把左右子树和当前节点的值都加上,来判断全局最大路径和

**AC代码:**

```java
class Solution {
    // 记录全局最大路径和
    int ret = Integer.MIN_VALUE;
    public int maxPathSum(TreeNode root) {
        dfs(root);
        return ret;
    }
    public int dfs(TreeNode root) {
        if(root == null) return 0;

        // 找左子树最大路径和
        // 要判断是否大于0, 不然会导致当前最大路径和(cur)还没当前根节点的值(root.val)大
        int leftMax = Math.max(dfs(root.left), 0);
        
        // 找右子树最大路径和
        // 此处同理
        int rightMax = Math.max(dfs(root.right), 0);

        // 记录当前最大路径和
        int cur = Math.max(leftMax, rightMax) + root.val;
        
        // 记录全局最大路径和
        ret = Math.max(ret, leftMax + rightMax + root.val);

        return cur;
    }
}
```

- **时间复杂度：O(n)**

  每个节点只被访问一次。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h（平衡树 O(log n)，链状树 O(n)）。
