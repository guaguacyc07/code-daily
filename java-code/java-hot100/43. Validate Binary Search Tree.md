# 43. Validate Binary Search Tree

- **题目 : [98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)**

> 难度: 中等
>
> 标签: 树, 深度优先搜索, 二叉搜索树

## 解法一

**思路:**

- 思路其实很简单, 前提是会中序遍历
- **二叉搜索树的中序遍历必定有序**
- 所以遍历一遍,然后看看是否有序就行了

**AC代码:**

```java
class Solution {
    List<Integer> ans = new ArrayList<>();
    public boolean isValidBST(TreeNode root) {
        dfs(root);
        // 二叉搜索树的中序遍历必定有序
        for(int i = 1;i < ans.size(); i++) {
            if(ans.get(i - 1) >= ans.get(i)) return false; 
        }
        return true;
    }
    // 中序遍历. 结果存进ans (左根右)
    void dfs(TreeNode root) {
        if(root == null) return;

        // 遍历左子树
        dfs(root.left);
        // 根
        ans.add(root.val);
        // 遍历右子树
        dfs(root.right);
    }
}
```

- **时间复杂度：O(n)**

  中序遍历一遍，再扫一遍数组检查是否严格递增。

- **空间复杂度：O(n)**

  数组存下全部 n 个节点值（另外还有递归栈 O(h)）。


## 解法二

对于解法一, 我们肯定还能继续优化的嘛

为什么要遍历完呢?

我们边遍历边看看是否满足有序不就行了

>  想法很美好, 看了下题解才明白

递归时传递当前节点的**取值上下界**，左子树的所有节点必须小于当前节点值（作为上界），右子树的所有节点必须大于当前节点值（作为下界）

使用`long`类型是为了避开节点值等于`Integer.MIN_VALUE` / `Integer.MAX_VALUE`时的边界错误

> 必须使用long, 不然ac不了

```java
class Solution {
    public boolean isValidBST(TreeNode root) {
        return dfs(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }
    // lower:下边界  upper:上边界 
    boolean dfs(TreeNode root, long lower, long upper) {
        if(root == null) return true;

        // 如果当前节点不在范围内, 返回false
        if(root.val <= lower || root.val >= upper) return false;

        // 遍历左子树时上边界收缩, 遍历右子树时下边界收缩
        return dfs(root.left, lower, root.val) 
            && dfs(root.right, root.val, upper);
    } 
}
```

- **时间复杂度：O(n)**

  每个节点只判断一次（不满足就短路返回）。

- **空间复杂度：O(h)**

  只有递归栈，深度为树高 h（对比解法一省掉了 O(n) 的数组）。
