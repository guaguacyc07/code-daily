# 87. Longest Increasing Subsequence

- **题目 : [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)**

> 难度: 中等
>
> 标签: 数组, 二分查找, 动态规划

## 解法一

```java
class Solution {
    public int lengthOfLIS(int[] nums) {
        int n = nums.length;

        int[] dp = new int[n];

        // 初始化, 每个元素自身是序列长为1的子序列
        for (int i = 0; i < n; i++) dp[i] = 1;

        // dp[i] 表示以nums[i]结尾的最长递增子序列的长度
        // 遍历0到i-1的每个j, 如果nums[i] > nums[j]
        // 那么说明可以把nums[i]接到nums[j]的后面
        // dp[i] = max(dp[i], dp[j] + 1)

        // 整个数组的最长递增子序列,不一定以数组的最后一个元素结尾
        // 所以要记录一下全局最长的长度
        int maxLen = 0;

        for (int i = 0; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (nums[i] > nums[j]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
            maxLen = Math.max(maxLen, dp[i]);
        }
        return maxLen;
    }
}
```

- **时间复杂度：O(n²)**

  两层循环枚举「以 i 结尾、上一个接的是 j」的所有情况。

- **空间复杂度：O(n)**

  `dp` 数组长度 n。
