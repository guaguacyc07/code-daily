# 58. Combination Sum

- **题目 : [39. 组合总和](https://leetcode.cn/problems/combination-sum/)**

> 难度: 中等
>
> 标签: 数组, 回溯

## 解法一

最开始, 我的错误在于, 他的答案会重复

原因在于: 我**允许了「回头选前面的元素」，导致同一个组合以不同的顺序被多次生成**。

我们用一个最直观的例子理解： 假设 `candidates = [2, 3]`，`target = 5`。 按照错误的代码逻辑：

- 第一层选 `2`，第二层可以再选 `2`、`3` → 得到 `[2, 3]`
- 第一层选 `3`，第二层可以再选 `2`、`3` → 得到 `[3, 2]`

对于「组合」来说，`[2, 3]` 和 `[3, 2]` 是完全相同的答案，但你的代码会把它们当成两条不同的路径存进去，这就是重复的根源。

WA代码:

```java
class Solution {
    List<List<Integer>> ret = new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        dfs(candidates, target, 0, new ArrayList<>());
        return ret;
    }
    void dfs(int[] candidates, int target, int curSum, List<Integer> ans) {
        // 出口
        if (curSum == target) {
            ret.add(new ArrayList<>(ans));
            return;
        } 
        if (curSum > target) return;

        for (int i = 0; i < candidates.length; i++) {
            // 把当前数组的数加进ans中
            ans.add(candidates[i]);
            curSum += candidates[i];
            // dfs找下个数
            dfs(candidates, target, curSum, ans);
            // 回溯
            ans.remove(ans.size() - 1);
            curSum -= candidates[i];
        }
    }
}
```

**解决方案**

**去重思路：给选取加上「下标不后退」的约束**

既然组合不关心顺序，我们就人为规定一条规则：

> 每次选元素，**只能从当前下标及之后的元素里选，不能选下标比当前小的元素**。

简单总结：**排列讲究顺序，所以每次可以从头选；组合不讲究顺序，所以必须禁止回头选**。

AC代码:

```java
class Solution {
    List<List<Integer>> ret = new ArrayList<>();
    public List<List<Integer>> combinationSum(int[] candidates, int target) {
        dfs(candidates, 0, target, 0, new ArrayList<>());
        return ret;
    }
    void dfs(int[] candidates, int start,int target, int curSum, List<Integer> ans) {
        // 出口
        if (curSum == target) {
            ret.add(new ArrayList<>(ans));
            return;
        } 
        if (curSum > target) return;

        for (int i = start; i < candidates.length; i++) {
            // 把当前数组的数加进ans中
            ans.add(candidates[i]);
            curSum += candidates[i];
            // dfs找下个数(start 从 i 开始, 不能选下标比当前小的元素)
            dfs(candidates, i, target, curSum, ans);
            // 回溯
            ans.remove(ans.size() - 1);
            curSum -= candidates[i];
        }
    }
}
```

- **时间复杂度：O(n^(T/M + 1))（指数级）**

  n 为 candidates 的长度，M 为其中最小的元素，T 为 target。搜索树深度最多 T / M + 1（每选一个数至少加上 M），每层最多 n 个分支，所以节点数上界是 O(n^(T/M + 1))；每个答案还要拷贝一份进结果集。实际因为有 `curSum > target` 提前返回，跑不到这个上界。

- **空间复杂度：O(T/M)**

  递归深度最多 T / M 层，当前路径 `ans` 的长度也不超过 T / M。不计返回的结果集。
