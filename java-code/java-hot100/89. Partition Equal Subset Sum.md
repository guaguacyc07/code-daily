# 89. Partition Equal Subset Sum

- **题目 : [416. 分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)**

> 难度: 中等
>
> 标签: 数组, 动态规划

## 解法一

```java
class Solution {
    public boolean canPartition(int[] nums) {
        // 假设总和是 s, 也就是说我们要凑出俩个子集
        // 这俩个子集的和都是 s / 2
        int s = 0;
        for (int num : nums) s += num;

        // 如果 s 是奇数, 说明不可能凑出来,直接返回false即可
        if (s % 2 == 1) return false;

        // 把s除以2, 这个就是我们要凑的值
        s /= 2;

        // 接下来就是思考,怎么从nums中, 挑选出一些数相加为s了
        // 这里本质是01背包, 选中一些数, 恰好为s

        // dp[i][j]表示: 从数组的前i个元素(nums[0] ~ nums[i-1])中挑选数字
        // 是否存在一种选法, 让选出的数字之和恰好等于j

        // 对于当前元素, 我们可以选择[选当前数]或者[不选当前数]

        // 1.如果不选第i个数(nums[i-1]): 那前i个数凑出j的可行性, 完全等于前i-1个数凑出j的可行性
        // 即dp[i][j] = dp[i-1][j]

        // 2.如果选第i个数(nums[i-1]): 
        // 要先保证 j >= nums[i-1] (目标和要比当前数大)
        // 然后我们要分析: 前i - 1个数能不能凑出j - nums[i-1]
        // 因为如果能凑出来, 那么加上当前这个数nums[i-1]就刚刚好凑出来j
        // 即dp[i][j] = dp[i-1][j - nums[i-1]]
        int n = nums.length;
        boolean[][] dp = new boolean[n + 1][s + 1];

        dp[0][0] = true;

        // 遍历每个数字(相当于物品)
        for (int i = 1; i <= n; i++) {
            int num = nums[i - 1]; // 当前第i个数
            // 遍历所有可能的和(背包的容量), 因为推导到s容量需要依赖前面信息
            for (int j = 0; j <= s; j++) {
                // 1. 不选当前数
                dp[i][j] = dp[i - 1][j];
                // 2. 如果背包容量够,放得下当前数, 那就加进去
                if (j >= num) {
                    // 在不选的基础上, 再叠加选第i个数的可能性,两种情况只要有一种能成功,当前状态就为true
                    dp[i][j] = dp[i][j] || dp[i - 1][j - num];
                }
            }
        }
        return dp[n][s];
    }
}
```

- **时间复杂度：O(n × s)**

  s 为总和的一半。两层循环：外层 n 个数，内层 0 到 s 的所有可能和。

- **空间复杂度：O(n × s)**

  二维 `dp` 表。其实每行只依赖上一行，可以压成一维的 `boolean[s + 1]`，空间降到 O(s)。
