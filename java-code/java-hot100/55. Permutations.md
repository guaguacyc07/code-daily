# 55. Permutations

- **题目 : [46. 全排列](https://leetcode.cn/problems/permutations/)**

> 难度: 中等
>
> 标签: 数组, 回溯

## 解法一

```java
class Solution {
    // 返回值
    List<List<Integer>> ret = new ArrayList<>();
    // 记录dfs时当前节点是否被使用过
    boolean[] used;
    public List<List<Integer>> permute(int[] nums) {
        used = new boolean[nums.length];
        dfs(nums, new ArrayList<>());
        return ret;
    }
    // dfs 
    void dfs(int[] nums, List<Integer> ans) {
        // 递归出口: 当前路径长度等于数组长度, 说明生成了一个完整排列
        if (ans.size() == nums.length) {
            // 不能直接存ans(后续会被修改)
            ret.add(new ArrayList<>(ans));
            return;
        }

        // 遍历所有元素，尝试选一个未使用的加入当前排列
        for (int i = 0; i < nums.length; i++) {
            // 如果当前遍历的节点被使用过, 就continue跳过
            if (used[i]) continue;

            // 如果没用过, 加入排列
            // 1. 先标记当前节点为使用过
            used[i] = true;

            // 2. 把当前节点加入ans数组中
            ans.add(nums[i]);
            // 3. 递归向下,填充下一个位置
            dfs(nums, ans);

            // 此时走到了这里,说明以当前选中的这个元素开头的所有排列都已经递归处理完毕
            // 那么就要回溯, 把加入数组的当前值移除, used数组设为false
            ans.remove(ans.size() - 1);
            used[i] = false;
        }
    }
}
```

- **时间复杂度：O(n × n!)**

  一共 n! 个排列（叶子节点），每个叶子要把长度 n 的 `ans` 拷贝一份存进结果，这一步 O(n)；递归树的内部节点总数也是 O(n!) 量级。两者加起来还是 O(n × n!)。

- **空间复杂度：O(n)**

  不计返回的结果集：递归深度最多 n 层，`used` 数组和当前路径 `ans` 长度都不超过 n。如果把 n! 个排列的结果集也算进去，就是 O(n × n!)。
