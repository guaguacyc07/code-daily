# 55. Permutations

- **题目 : [46. 全排列](https://leetcode.cn/problems/permutations/)**

> 难度: 中等
>
> 标签: 数组, 回溯

## 解法一

回溯（DFS 穷举）。把"生成一个排列"看成依次给第 0、1、2 ... n-1 个位置选数，每层递归选一个还没用过的数放到当前位置：

1. `used[i]` 标记 `nums[i]` 有没有被选过，`ans` 记录当前这条路径，也就是正在拼的那个排列。
2. 每层遍历所有元素，跳过用过的；把可用的元素标记为已用、加进 `ans`，然后递归进入下一层填下一个位置。
3. 当 `ans.size() == n`，说明已经凑出一个完整排列，把它**拷贝一份**放进结果集，然后返回。
4. 递归返回后要撤销选择：把刚加进去的元素从 `ans` 末尾删掉，`used[i]` 改回 `false`，这样同一层才能接着试别的元素。

这里有个容易踩的坑：`ret.add(new ArrayList<>(ans))` 必须 new 一个新的 list。`ans` 是全程共用的，后面回溯会不停增删，如果直接存引用，最后结果里全是指向同一个空列表的引用。

以 `[1,2,3]` 为例，第一层分别选 1、2、3，每条分支在剩下的数里继续选，一共 3! = 6 条走到叶子的路径，正好对应 6 个排列。

```java
class Solution {
    // 返回值
    List<List<Integer>> ret = new ArrayList<>();
    // 记录dfs时当前节点是否被使用过
    boolean[] used;
    public List<List<Integer>> permute(int[] nums) {
        used = new boolean[nums.length];
        dfs(nums, new ArrayList<>());
        return ret;
    }
    // dfs 
    void dfs(int[] nums, List<Integer> ans) {
        // 递归出口: 当前路径长度等于数组长度, 说明生成了一个完整排列
        if (ans.size() == nums.length) {
            // 不能直接存ans(后续会被修改)
            ret.add(new ArrayList<>(ans));
            return;
        }

        // 遍历所有元素，尝试选一个未使用的加入当前排列
        for (int i = 0; i < nums.length; i++) {
            // 如果当前遍历的节点被使用过, 就continue跳过
            if (used[i]) continue;

            // 如果没用过, 加入排列
            // 1. 先标记当前节点为使用过
            used[i] = true;

            // 2. 把当前节点加入ans数组中
            ans.add(nums[i]);
            // 3. 递归向下,填充下一个位置
            dfs(nums, ans);

            // 此时走到了这里,说明以当前选中的这个元素开头的所有排列都已经递归处理完毕
            // 那么就要回溯, 把加入数组的当前值移除, used数组设为false
            ans.remove(ans.size() - 1);
            used[i] = false;
        }
    }
}
```

- **时间复杂度：O(n × n!)**

  一共 n! 个排列（叶子节点），每个叶子要把长度 n 的 `ans` 拷贝一份存进结果，这一步 O(n)；递归树的内部节点总数也是 O(n!) 量级。两者加起来还是 O(n × n!)。

- **空间复杂度：O(n)**

  不计返回的结果集：递归深度最多 n 层，`used` 数组和当前路径 `ans` 长度都不超过 n。如果把 n! 个排列的结果集也算进去，就是 O(n × n!)。
