# 36. Binary Tree Inorder Traversal

- **题目 : [94. 二叉树的中序遍历](https://leetcode.cn/problems/binary-tree-inorder-traversal/)**

> 难度: 简单
>
> 标签: 栈, 树, 深度优先搜索

## 解法一(递归)

>**二叉树三种遍历（根的访问顺序区分）**
>
>1. **前序遍历**：根 → 左 → 右 先访问根节点，再遍历左子树，最后右子树。
>2. **中序遍历**：左 → 根 → 右 先遍历左子树，再访问根节点，最后右子树。二叉搜索树中序遍历结果是有序序列。
>3. **后序遍历**：左 → 右 → 根 先遍历左、右子树，最后才访问根节点。适合删除节点、统计子树信息。
>
>一句话记忆：**前根中根后根，左右永远先左后右**。

**思路:**

- 对于递归, 我觉得我们不应该也尽量不要去关注他的过程, 而是注重结果
- 对于这里, 我们递归函数就干了一件事, 他的结果是遍历完了左子树 , 根节点, 右子树
- 也许我们可以这么理解
- 先遍历左子树, 当左子树走到尽头(null), 那么当前的根节点就是按顺序遍历到的元素
- 然后遍历右子树, 遍历右子树的时候, 又会再把相应左子树走到尽头

**AC代码:**

```java
class Solution {
    List<Integer> ret = new ArrayList<>();
    public List<Integer> inorderTraversal(TreeNode root) {
        // 递归解法
        // 中序遍历 -- 左,根,右
        dfs(root);
        return ret;
    }
    void dfs(TreeNode root) {
        if(root == null) return;
        
        // 遍历左子树
        dfs(root.left);
        // 当前是根节点, 把值加入结果集
        ret.add(root.val);
        // 遍历右子树
        dfs(root.right);       
    }
}
```

- **时间复杂度：O(n)**

  每个节点恰好被访问一次。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h（最坏是链状树，O(n)）。

## 解法二(迭代)

本质思路和递归没区别

一个是函数调用栈, 一个是手动调用栈

```java
class Solution {
    public List<Integer> inorderTraversal(TreeNode root) {
        List<Integer> ret = new ArrayList<>();
        // 双端队列模拟栈
        Deque<TreeNode> stack = new ArrayDeque<>();
        TreeNode cur = root;

        while(cur != null || !stack.isEmpty()) {
            // 遍历左子树, 并存入栈
            while(cur != null) {
                stack.push(cur);
                cur = cur.left;
            }
            // 左走到头, 弹出当前栈顶
            cur = stack.pop();
            ret.add(cur.val);

            // 遍历右子树
            cur = cur.right;
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  每个节点入栈、出栈各一次。

- **空间复杂度：O(h)**

  显式栈最多同时压入一条左链，即树高 h 个节点。
