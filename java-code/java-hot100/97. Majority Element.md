```java
    // 3. 摩尔投票(最优)
    public int majorityElement(int[] nums) {
        int count = 0;
        int ans = 0;

        for(int num : nums) {
            if(count == 0) {
                ans = num;
            }
            count += (ans == num) ? 1 : -1;
        }
        return ans;
    }

}
```

- **时间复杂度：O(n)**

  摩尔投票只遍历一遍数组。

- **空间复杂度：O(1)**

  只用了 count、ans 两个变量。
