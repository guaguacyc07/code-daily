# 59. Generate Parentheses

- **题目 : [22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)**

> 难度: 中等
>
> 标签: 字符串, 动态规划, 回溯

## 解法一

```java
class Solution {
    List<String> ret = new ArrayList<>();
    public List<String> generateParenthesis(int n) {
        dfs(n, new StringBuilder(), 0, 0);
        return ret;
    }
    // left表示左括号的数量, right同理
    void dfs(int n, StringBuilder ans, int left, int right) {
        // 出口
        if (ans.length() == n * 2) {
            ret.add(ans.toString());
            return;
        }

        // 每一次递归, 都要判断, 该加左括号还是右括号, 以及能不能加
        // 1. 判断是否可以加左括号
        if (left < n) {
            ans.append('(');
            // 递归到下一层继续判断
            dfs(n, ans, left + 1, right);
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
        } 
        // 2. 判断是否可以加右括号(这里要注意, 不是right < n)
        // 只有当right < left(右括号数量少于左括号数量才能加右括号)
        // 不然会出现")))((("这种情况
        if (right < left) {
            ans.append(')');
            // 递归到下一层继续判断
            dfs(n, ans, left, right + 1);
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
        }
    }    
}
```

- **时间复杂度：O(4^n / √n)**

  合法括号串的个数是第 n 个卡特兰数 C_n ≈ 4^n / (n^1.5 · √π)。每个合法串在叶子处用 `ans.toString()` 生成，这一步 O(n)，所以总时间是 O(n · C_n) = O(4^n / √n)。

- **空间复杂度：O(n)**

  递归深度最多 2n 层，`StringBuilder` 长度最多 2n，两个计数器是常数空间。不计返回的结果集。
