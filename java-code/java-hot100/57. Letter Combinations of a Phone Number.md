# 57. Letter Combinations of a Phone Number

- **题目 : [17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)**

> 难度: 中等
>
> 标签: 哈希表, 字符串, 回溯

## 解法一

```java
class Solution {
    // 结果集
    List<String> ret = new ArrayList<>();
    public List<String> letterCombinations(String digits) {
        // 用map去存储数字和对应的字母
        Map<Character, String> map = new HashMap<>();
        map.put('2', "abc");
        map.put('3', "def");
        map.put('4', "ghi");
        map.put('5', "jkl");
        map.put('6', "mno");
        map.put('7', "pqrs");
        map.put('8', "tuv");
        map.put('9', "wxyz");

        dfs(digits, 0, new StringBuffer(), map);
        return ret;
    }
    // dfs 
    void dfs(String digits, int idx, StringBuffer ans, Map<Character, String> map) {
        // 出口
        if (digits.length() == ans.length()) {
            ret.add(new String(ans));
            return;
        }
        // 获取当前idx对应的数字
        char digit = digits.charAt(idx);
        // 取出对应map里的字符串
        String letters = map.get(digit);
        // 遍历letters每个字符, 依次加入ans
        for (int i = 0; i < letters.length(); i++) {
            ans.append(letters.charAt(i));
            // 递归下个idx对应的数字
            dfs(digits, idx + 1, ans, map);
            // 回溯
            ans.deleteCharAt(ans.length() - 1);
        }
    }
}
```

- **时间复杂度：O(n × 4^n)**

  n 为 digits 的长度。最坏情况每个数字对应 4 个字母（7 和 9），一共能组合出 4^n 个结果；每个叶子要用 `new String(ans)` 生成一个长度 n 的字符串，这一步 O(n)。合起来是 O(n × 4^n)。

- **空间复杂度：O(n)**

  不计返回的结果集：递归深度最多 n 层，`StringBuffer` 的长度不超过 n，`map` 固定 8 项。如果把 4^n 个结果字符串也算进去，就是 O(n × 4^n)。
