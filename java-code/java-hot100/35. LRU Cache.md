# 35. LRU Cache

- **题目 : [146. LRU 缓存](https://leetcode.cn/problems/lru-cache/)**

> 难度: 中等
>
> 标签: 设计, 哈希表, 链表

## 解法一

思路:

- 如何让`get`和`put`都以`O(1)`平均时间复杂度呢?
- `put`需要先判断关键字`key`是否已经存在
- 如何写出时间复杂度为`O(1)`的`put`
- 可以考虑用链表 -- 增删改为`O(1)`
- 如何写出时间复杂度为`O(1)`的`get`
- 可以考虑用Map存储 -- key: 链表节点的关键字key  | value: 链表节点对象
- 这里得用双向链表, 方便修改

**AC代码:**

```java
class LRUCache {
    class Node {
        int key,val;
        Node pre,next;

        public Node(){}
        public Node(int key, int val){
            this.key = key; 
            this.val = val;
        }
    }

    // key存Node的key, value存Node对象
    Map<Integer, Node> map = new HashMap<>();
    // size 记录当前链表长度
    int size;
    // 记录容量
    int capacity;
    // 记录头尾节点
    Node head,tail;

    public LRUCache(int capacity) {
        this.size = 0;
        this.capacity = capacity;
        head = new Node();
        tail = new Node();

        head.next = tail;
        tail.pre = head;
    }
    
    public int get(int key) {
        Node node = map.get(key);
        if(node == null){
            return -1;
        }
        // 命中, 先去除当前节点
        node.pre.next = node.next;
        node.next.pre = node.pre;
        // 头插放到head后面
        node.pre = head;
        node.next = head.next;
        head.next.pre = node;
        head.next = node;
        return node.val;
    }
    
    public Node getNode(int key) {
        Node node = map.get(key);
        return node;
    }

    public void put(int key, int value) {
        // 头插法插入链表, 先判断是否存在
        if(getNode(key) == null) {
            Node node = new Node(key, value);
            Node nxt = head.next;

            head.next = node;
            node.pre = head;
        
            node.next = nxt;
            nxt.pre = node;
            // 把当前插入链表的节点放入map
            map.put(key, node);
            size++;
            // 判断size是否大于capacity
            if(size > capacity) {
                // 如果大于, 移除tail的前一个节点, 且移除map里面的数据
                Node tailNode = tail.pre;
                tailNode.pre.next = tail;
                tail.pre = tailNode.pre;
                tailNode.pre = null;
                map.remove(tailNode.key);
                size--;
            }
        } else {
            // 存在的话, 就把节点移到链表头
            Node node = map.get(key);
            node.pre.next = node.next;
            node.next.pre = node.pre;

            node.pre = head;
            node.next = head.next;
            head.next.pre = node;
            head.next = node;
            node.val = value;
        }
        
    }
}
```

- **时间复杂度：O(1)**

  `get` / `put` 平均都是 O(1)：`HashMap` 查找 O(1)，双向链表在哨兵头尾处增删节点也是 O(1)。

- **空间复杂度：O(capacity)**

  `map` 与双向链表最多各存 capacity 个节点（超出就淘汰尾部的最近最少使用节点）。
