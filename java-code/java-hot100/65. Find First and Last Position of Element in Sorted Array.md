# 65. Find First and Last Position of Element in Sorted Array

- **题目 : [34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)**

> 难度: 中等
>
> 标签: 数组, 二分查找

## 解法一

```java
class Solution {
    public int[] searchRange(int[] nums, int target) {
        // 空数组直接返回结果
        if (nums.length == 0) {
            return new int[]{-1, -1};
        }
        int leftBorder = findLeft(nums, target);
        int rightBorder = findRight(nums, target);
        // 校验目标值是否真实存在
        if (nums[leftBorder] != target) {
            return new int[]{-1, -1};
        }

        return new int[]{leftBorder, rightBorder};
    }
    // while (left < right)作为终止条件,循环退出的唯一时刻就是 left == right
    int findLeft(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        // 找左边界
        while (left < right) {
            // 此处向下取整
            int mid = (left + right) >> 1;
            if (nums[mid] >= target) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }
        // 此时的left或right都是左边界的索引
        return left;
        // return right;  --- 这么写也行
    }
    int findRight(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        // 找右边界
        while (left < right) {
            // 此处向上取整
            int mid = (left + right + 1) >> 1;
            if (nums[mid] <= target) {
                left = mid;
            } else {
                right = mid - 1;
            }
        }
        // 此时的left或right都是右边界的索引
        return left;
        // return right;  --- 这么写也行
    }
}
```

- **时间复杂度：O(log n)**

  两趟二分：`findLeft` 找第一个 ≥ target 的位置，`findRight` 找最后一个 ≤ target 的位置，各自 O(log n)。

- **空间复杂度：O(1)**

  只用了 left、right、mid 几个变量，没有递归。
