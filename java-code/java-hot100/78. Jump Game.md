# 78. Jump Game

- **题目 : [55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)**

> 难度: 中等
>
> 标签: 贪心, 数组, 动态规划

## 解法一(动态规划)

```java
class Solution {
    public boolean canJump(int[] nums) {
        // 解法1: 动态规划
        // 首先分析一下状态转移方程
        // dp[i] 表示是否可以到达索引i, 可以为true, 否则为false
        // 那么, 在 0 到 i 中, 只要存在一个 dp[j] = true 且 nums[j] >= i - j
        // 就说明dp[i] 也是可达的, 否则就是不可达
        int n = nums.length;
        boolean[] dp = new boolean[n];

        dp[0] = true;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && nums[j] >= (i - j)) {
                    dp[i] = true;
                } 
            }
        }     
        return dp[n - 1];
    }
}
```

- **时间复杂度：O(n²)**

  两层循环枚举「从哪个 j 跳到 i」。

- **空间复杂度：O(n)**

  `dp` 数组长度 n。

## 解法二(贪心)

```java
class Solution {
    public boolean canJump(int[] nums) {
        // 解法2: 贪心
        // 首先, 如果位置i是可达的, 那么 0 到 i 的全部位置也都是可达的
        // 所以, 我们只管最大能跳多远就行了
        int n = nums.length;
        // 可以到达的最远位置
        int max = 0;

        for (int i = 0; i < n; i++) {
            // 如果 i 大于 max, 说明当前位置 i 是不可达的
            if (i > max) return false;
            max = Math.max(max, i + nums[i]);
        } 
        
        return max >= (n - 1);
    }
}
```

- **时间复杂度：O(n)**

  只扫一遍，边扫边维护「能跳到的最远位置」。

- **空间复杂度：O(1)**

  只用了 max 一个变量。
