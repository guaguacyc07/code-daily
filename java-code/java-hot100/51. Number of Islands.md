# 51. Number of Islands

- **题目 : [200. 岛屿数量](https://leetcode.cn/problems/number-of-islands/)**

> 难度: 中等
>
> 标签: 深度优先搜索, 广度优先搜索, 并查集

## 解法一

思路:

- 每次我们遍历到一个健康节点, 就把他和他相连的节点全部污染
- 具体看注释和代码, 注释写的很清晰

**AC代码:**

```java
class Solution {
    public int numIslands(char[][] grid) {
        // 遍历所有坐标
        int ans = 0;
        for (int i = 0; i < grid.length; i++) {
            for (int j = 0; j < grid[0].length; j++) {
                // 如果当前岛屿为'1'就把ans加1, 因为一旦遍历到一个没被污染的岛屿
                // 那么和他相连的全部岛屿都会被污染, 后续是遍历不到的
                if (grid[i][j] == '1') ans++;
                // 开始污染当前岛屿以及相连的全部岛屿
                dfs(grid, i, j);
            }
        }
        return ans;
    }

    // 污染当前所在的岛屿(参数: 要遍历的数组和当前遍历的坐标(x, y))
    // 把遍历过的数值为 '1' 的岛屿污染为 '2'
    void dfs(char[][] grid, int x, int y) {
        // 遍历出了边界(返回)
        if (!inArea(grid, x, y)) return;

        // 判断当前坐标是否已经遍历过(不为'1'就是遍历过('0'的话要跳过,可以当遍历过算))
        if (grid[x][y] != '1') return;

        //把当前坐标污染先
        grid[x][y] = '2';

        // 开始污染岛屿
        // 污染坐标上边
        dfs(grid, x, y - 1);
        // 污染坐标左边
        dfs(grid, x - 1, y);
        // 污染坐标下边
        dfs(grid, x, y + 1);
        // 污染坐标右边
        dfs(grid, x + 1, y);

    }
    // 判断当前坐标是否合理(在数组范围内)
    // 在: 返回true   不在: 返回false
    boolean inArea(char[][] grid, int x, int y) {
        return 0 <= x && x < grid.length && 0 <= y && y < grid[0].length;
    }
}
```

- **时间复杂度：O(m·n)**

  每个格子最多被 `dfs` 访问常数次（进入后只要不是 `'1'` 就立即返回），外层双层循环也是 m×n。

- **空间复杂度：O(m·n)**

  递归栈的最坏深度等于一整块岛屿的格子数（比如整片陆地连成一条长蛇）；除此之外没有开额外数组（"污染"是就地改原数组）。
