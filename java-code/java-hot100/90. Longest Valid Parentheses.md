# 90. Longest Valid Parentheses

- **题目 : [32. 最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/)**

> 难度: 困难
>
> 标签: 栈, 字符串, 动态规划

## 解法一

```java
class Solution {
    public int longestValidParentheses(String s) {
        // 有效括号的本质是: 每个右括号,都能找到左侧最近的还没配对的左括号
        // 可以用栈来存还没配对的左括号的下标
        int n = s.length();

        // 用一个布尔数组记录是否配对成功
        boolean[] flag = new boolean[n]; // flag[i]表示第i个位置是否配对成功
        // 栈(未配对的左括号的下标)
        Deque<Integer> stack = new ArrayDeque<>();

        // 标记哪些括号是配对好的
        for (int i = 0; i < n; i++) {
            // 如果是左括号, 保存下标进栈
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                // 如果是右括号, 分2种情况            
                if (!stack.isEmpty()) {
                    // 1. 栈不为空, 栈顶就是最近的未匹配左括号, 二者匹配
                    // 把当前右括号位置i标记为true
                    flag[i] = true;
                    // 把栈顶左括号的位置也标记为true, 顺便出栈
                    flag[stack.pop()] = true;
                }
                // 2. 栈为空
                // 不用做处理      
            }
        }
        // 标记好后, 问题就变简单了
        // 找到最长的连续true
        int ret = 0;
        int cur = 0;
        for (int i = 0; i < n; i++) {
            if (flag[i]) {
                cur++;
                ret = Math.max(ret, cur);
            } else {
                cur = 0;
            }
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  一趟括号匹配 + 一趟找最长连续 true，都是线性的。

- **空间复杂度：O(n)**

  `flag` 数组和栈各 O(n)。
