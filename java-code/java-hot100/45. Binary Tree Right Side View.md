# 45. Binary Tree Right Side View

- **题目 : [199. 二叉树的右视图](https://leetcode.cn/problems/binary-tree-right-side-view/)**

> 难度: 中等
>
> 标签: 树, 深度优先搜索, 广度优先搜索

## 解法一

**前情提要:[102. 二叉树的层序遍历](41.%20Binary%20Tree%20Level%20Order%20Traversal.md)**

**思路:**

- 其实就是在bfs的过程中把最后一个节点加进 `ret` 集合

**AC代码:**

```java
class Solution {
    public List<Integer> rightSideView(TreeNode root) {
        List<Integer> ret = new ArrayList<>();
        if(root == null) return ret;
        // bfs进行层序遍历,然后把队列的最后一个元素加入ret
        Queue<TreeNode> q = new ArrayDeque<>();
        q.offer(root);

        while(!q.isEmpty()) {
            // 获取当前层的节点数
            int size = q.size();
            for(int i = 0; i < size; i++) {
                TreeNode cur = q.poll();
                if(i == size - 1) ret.add(cur.val);
                if(cur.left != null) q.offer(cur.left);
                if(cur.right != null) q.offer(cur.right);
            }
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  每个节点入队、出队各一次。

- **空间复杂度：O(w)**

  队列里最多同时存一层的节点，w 为树的最大宽度（完全二叉树最坏约 n/2，即 O(n)）。
