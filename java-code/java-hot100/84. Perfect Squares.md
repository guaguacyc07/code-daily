# 84. Perfect Squares

- **题目 : [279. 完全平方数](https://leetcode.cn/problems/perfect-squares/)**

> 难度: 中等
>
> 标签: 广度优先搜索, 数学, 动态规划

## 解法一

```java
class Solution {
    public int numSquares(int n) {
        int[] dp = new int[10010];

        // 初始化
        Arrays.fill(dp, n + 1);

        dp[0] = 0;
        
        for(int i = 1; i <= n; i++){
            for(int j = 1; j * j <= i; j++){
                dp[i] = Math.min(dp[i],dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
}
```

- **时间复杂度：O(n√n)**

  外层 1 到 n，内层枚举不超过 √i 个完全平方数。

- **空间复杂度：O(n)**

  `dp` 数组按题目上限开成了固定长度 10010（本题 n ≤ 10⁴），按 n 记作 O(n)。
