# 84. Perfect Squares

- **题目 : [279. 完全平方数](https://leetcode.cn/problems/perfect-squares/)**

> 难度: 中等
>
> 标签: 广度优先搜索, 数学, 动态规划

## 解法一

```java
class Solution {
    public int numSquares(int n) {
        // dp[i]: 凑出数字i所需要的最少完全平方数的个数
        int[] dp = new int[n + 1];

        // 初始化, 最大也就是全用1组成, 所以有n+1个
        Arrays.fill(dp, n + 1);

        // 要得到 dp[i], 最后一步我可以做什么选择？
        // 我们的目标是凑出数字 i, 那最后一步一定是选了某个完全平方数j*j(这个j*j必须≤i)
        // i-j*j: 选了j*j这个平方数之后,剩下还需要凑的数字
        // +1: 就是我们刚刚选的这个平方数j*j
        // Math.min(...):在所有可选的方案里, 挑出用的平方数个数最少的那一个
        dp[0] = 0;

        for(int i = 1; i <= n; i++){
            for(int j = 1; j * j <= i; j++){
                dp[i] = Math.min(dp[i],dp[i - j * j] + 1);
            }
        }

        return dp[n];
    }
}
```

- **时间复杂度：O(n√n)**

  外层 1 到 n，内层枚举不超过 √i 个完全平方数。

- **空间复杂度：O(n)**

  `dp` 数组长度 n + 1。
