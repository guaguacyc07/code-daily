# 88. Maximum Product Subarray

- **题目 : [152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)**

> 难度: 中等
>
> 标签: 数组, 动态规划

## 解法一

```java
class Solution {
    public int maxProduct(int[] nums) {
        // dp[i] 表示以nums[i]结尾的连续子数组的最大乘积
        // 我们要思考一个很关键的问题
        // nums是存在负数的,也就是说会有 负负得正 的情况
        // 那么一个dp[i]可能不太够
        // 所以: 
        // 1. 用dpMax[i]来记录以nums[i]结尾的连续子数组的最大乘积
        // 2. 再来一个dpMin[i]来记录以nums[i]结尾的连续子数组的最小乘积
        // 对于最小值是负数时, 在遇到负数时会反转成最大值
        int n = nums.length;
        int[] dpMax = new int[n];
        int[] dpMin = new int[n];

        // 初始化
        dpMax[0] = nums[0];
        dpMin[0] = nums[0];

        // 维护一个全局的最大值, 用来当结果返回
        int ret = nums[0];

        // 以nums[i]结尾的连续子数组, 只有两种可能
        // 1. 子数组只有nums[i]一个数
        // 2. 子数组 = 以nums[i-1]结尾的某个连续子数组 + nums[i]
        for (int i = 1; i < n; i++) {
            dpMax[i] = Math.max(nums[i], Math.max(dpMax[i - 1] * nums[i], dpMin[i - 1] * nums[i]));
            dpMin[i] = Math.min(nums[i], Math.min(dpMax[i - 1] * nums[i], dpMin[i - 1] * nums[i]));
            ret = Math.max(ret, dpMax[i]);
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  从第二个元素递推到最后一个，每步 O(1)。

- **空间复杂度：O(n)**

  `dpMax`、`dpMin` 两个数组各长度 n；其实每项只依赖前一项，可以滚成两个变量做到 O(1)。
