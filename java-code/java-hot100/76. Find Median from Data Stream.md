# 76. Find Median from Data Stream

- **题目 : [295. 数据流的中位数](https://leetcode.cn/problems/find-median-from-data-stream/)**

> 难度: 困难
>
> 标签: 设计, 双指针, 数据流, 堆

## 解法一

```java
class MedianFinder {
    // 用大根堆去存放左半部分的元素
    private PriorityQueue<Integer> leftHeap;
    // 用小根堆去存放右半部分的元素
    private PriorityQueue<Integer> rightHeap;
    // 要保证大根堆的个数(左部分) >= 小根堆的个数(右部分)
    // 一旦大根堆个数小于小根堆个数, 那么就把小根堆的堆顶放到大根堆去
    // 对于获取中位数
    // 1. 如果 大根堆个数(左部分) > 小根堆个数(右部分) 
    // -- 说明是奇数个, 直接返回大根堆堆顶即可
    // 2. 如果 大根堆个数(左部分) = 小根堆个数(右部分) 
    // -- 说明是偶数个, 返回 (大根堆堆顶 + 小根堆堆顶) / 2.0即可

    public MedianFinder() {
        // 大根堆放左边元素
        leftHeap = new PriorityQueue<>((a, b) -> b - a);
        // 小根堆放右边元素
        rightHeap = new PriorityQueue<>();    
    }
    
    public void addNum(int num) {
        // 放进右堆
        rightHeap.offer(num);
        // 把右堆的堆顶放进左堆(相当于排了下序)
        leftHeap.offer(rightHeap.poll());
        // 如果左堆比右堆多了2个, 就把左堆最大值移回右堆, 维持平衡
        if (leftHeap.size() > rightHeap.size() + 1) {
            rightHeap.offer(leftHeap.poll());
        }
    }
    
    public double findMedian() {
        if (leftHeap.size() > rightHeap.size()) return leftHeap.peek();
        else return (leftHeap.peek() + rightHeap.peek()) / 2.0;
    }
}

/**
 * Your MedianFinder object will be instantiated and called as such:
 * MedianFinder obj = new MedianFinder();
 * obj.addNum(num);
 * double param_2 = obj.findMedian();
 */
```

- **时间复杂度：addNum 为 O(log n)，findMedian 为 O(1)**

  `addNum` 只做堆的插入和弹出，每次 O(log n)；`findMedian` 直接取两个堆顶，不遍历元素。

- **空间复杂度：O(n)**

  两个堆加起来存下所有数据。
