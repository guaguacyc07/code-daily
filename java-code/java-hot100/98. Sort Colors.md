# 98. Sort Colors

- **题目 : [75. 颜色分类](https://leetcode.cn/problems/sort-colors/)**

> 难度: 中等
>
> 标签: 数组, 双指针, 排序

## 解法一

```java
class Solution {
    public void sortColors(int[] nums) {
        // 分别统计数组中 0, 1, 2 出现的次数
        int count0 = 0, count1 = 0, count2 = 0;
        // 第一次遍历: 逐个计数, 统计每个颜色的数量
        for(int i = 0; i < nums.length; i++){
            if(nums[i] == 0) count0++; // 遇到 0, 0 的计数 +1
            else if(nums[i]== 1) count1++; // 遇到 1, 1 的计数 +1
            else if(nums[i]==2) count2++; // 遇到 2, 2 的计数 +1
        }
        // 回填 0: 数组前 count0 个位置全部赋值为 0
        for(int i = 0; i < count0; i++){
            nums[i] = 0;
        }
        // 回填 1: 从 count0 位置开始, 连续 count1 个位置赋值为 1
        for(int i = count0; i < count0 + count1; i++){
            nums[i] =1;
        }
        // 回填 2: 从 count1 + count2 位置开始, 剩余位置赋值为 2
        for(int i = count0 + count1; i< count0 + count1 + count2; i++){
            nums[i] = 2;
        }
    }
}
```

- **时间复杂度：O(n)**

  一趟统计 + 三趟回填，总共不超过 2n 次操作。

- **空间复杂度：O(1)**

  只用了 count0、count1、count2 三个变量。
