# 47. Construct Binary Tree from Preorder and Inorder Traversal

- **题目 : [105. 从前序与中序遍历序列构造二叉树](https://leetcode.cn/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)**

> 难度: 中等
>
> 标签: 树, 数组, 哈希表, 分治

## 解法一

**核心原理**

1. 前序遍历顺序：「根 → 左子树 → 右子树」，**前序序列的第一个元素，就是整棵树的根节点**
2. 在中序序列中找到根节点的位置：
   - 根左边的所有元素 → 左子树的中序序列
   - 根右边的所有元素 → 右子树的中序序列
3. 根据左右子树的节点数量，在前序序列中对应切分出左、右子树的前序序列
4. 对左右子树分别递归执行上述逻辑，直到序列为空

**AC代码:**

```java
class Solution {
    public TreeNode buildTree(int[] preorder, int[] inorder) {
        // 前序 -- 根, 左, 右
        // 中序 -- 左, 根, 右
        return dfs(preorder, 0, preorder.length - 1,
                   inorder, 0, inorder.length - 1);
    }
    TreeNode dfs(int[] preorder, int preStart, int preEnd, 
                 int[] inorder, int inStart, int inEnd) {
        
        // 递归出口
        if (preStart > preEnd || inStart > inEnd) return null;

        // 前序的第一个元素是根
        int rootVal = preorder[preStart];
        TreeNode root = new TreeNode(rootVal);

        // 找到根在中序遍历数组中的位置
        int rootIdx = inStart;
        while (rootVal != inorder[rootIdx]) {
            rootIdx++;
        }

        // 左子树的节点数
        int leftSize = rootIdx - inStart;

        // 构造左右子树
        root.left = dfs(preorder, preStart + 1, preStart + leftSize,
                        inorder, inStart, rootIdx - 1);

        root.right = dfs(preorder, preStart + 1 + leftSize, preEnd,
                         inorder, rootIdx + 1, inEnd);
        
        return root;
    }
}
```

- **时间复杂度：O(n²)**

  每层递归都用 `while` **线性扫描**中序数组找根的位置，最坏情况（链状树）是 n + (n-1) + … = O(n²)。

  > 💡 若先用哈希表存好「值 → 中序下标」，每层查根变成 O(1)，整体就能优化到 **O(n)**。

- **空间复杂度：O(h)**

  只有递归栈（数组按下标传递，没有复制），深度等于树高 h。
