# 64. Search a 2D Matrix

- **题目 : [74. 搜索二维矩阵](https://leetcode.cn/problems/search-a-2d-matrix/)**

> 难度: 中等
>
> 标签: 数组, 二分查找, 矩阵

## 解法一

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // 空矩阵边界处理
        if (matrix == null || matrix.length == 0 || matrix[0].length == 0) {
            return false;
        }

        // 两次二分查找
        int m = matrix.length - 1, n = matrix[0].length - 1;

        // 先找行
        int left = 0, right = m;
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (matrix[mid][0] <= target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        // 此时right是对应要查找的行数
        int row = right;
        left = 0;
        right = n;
        // 防止 target 小于所有行首
        if (row < 0) { 
            return false;
        }
        // 开始找列
        while (left <= right) {
            int mid = (left + right) >> 1;
            if (matrix[row][mid] <= target) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        if (target == matrix[row][right]) return true;
        return false;
    }
}
```

- **时间复杂度：O(log m + log n)**

  先对 m 行做一次二分找目标可能所在的行，再对这一行 n 个元素做一次二分；两次都是标准二分，合起来 O(log m + log n)，也可以写成 O(log(m·n))。

- **空间复杂度：O(1)**

  只用了 left、right、mid、row 几个变量。
