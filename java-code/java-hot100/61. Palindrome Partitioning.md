## 解法一

>两种基本回溯思想：**选或不选**、**枚举选哪个**

AC代码

```java
// 枚举选哪个
class Solution {
    List<List<String>> ret = new ArrayList<>();
    public List<List<String>> partition(String s) {
        dfs(s, new ArrayList<>(), 0);
        return ret;
    }
    // 在每个字符中间都来切一刀, 如果是回文就分割加进ans
    // 然后s未被分割的部分为 [idx, n-1]
    void dfs(String s, List<String> ans, int idx) {
        // 递归出口(当递归到结尾, 无法切的时候就是出口)
        if (s.length() == idx) {
            ret.add(new ArrayList<>(ans));
            return;
        }

        for (int i = idx; i < s.length(); i++) {
            // 判断[idx, i]是不是回文串
            String cur = s.substring(idx, i + 1);
            // 不是回文就跳过
            if (!isPalindrome(cur)) continue;
            ans.add(cur);
            dfs(s, ans, i + 1);
            // 回溯
            ans.remove(ans.size() - 1);
        }
    }
    // 判断是否为回文
    boolean isPalindrome(String str) {
        int left = 0, right = str.length() - 1;
        while (left < right) {
            if (str.charAt(left) != str.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```





- **时间复杂度：O(n·2^n)**

  n 为字符串长度。最坏情况（比如全是同一个字符）每个位置都可以切或不切，搜索树节点数是 2^n 量级；每个节点还要做一次 `substring` + 回文判断，各 O(n)。所以是 O(n·2^n)。

- **空间复杂度：O(n)**

  递归深度最多 n 层，当前路径 `ans` 里所有片段的总长度不超过 n。不计返回的结果集。

## 解法二

```java
// 选或不选
class Solution {
    List<List<String>> ret = new ArrayList<>();
    public List<List<String>> partition(String s) {
        dfs(s, new ArrayList<>(), 0, 0);
        return ret;
    }
    // 未切部分[start, s.length() - 1]
    // 当前位于下标idx, 选择是否在idx和idx + 1之间切一刀
    void dfs(String s, List<String> ans, int idx, int start) {
        // 如果idx到了末尾,说明没有可以切的了,返回
        if (s.length() == idx) {
            ret.add(new ArrayList<>(ans));
            return;
        }
        // 跳过, 不切
        // idx = n-1 时必须分割（这是最后一段），idx < n-1 时才可以不分割
        if (idx < s.length() - 1) {
            dfs(s, ans, idx + 1, start);
        }

        // 选择切
        String cur = s.substring(start, idx + 1);
        if (!isPalindrome(cur)) return;
        // 如果是回文
        ans.add(cur);
        dfs(s, ans, idx + 1, idx + 1);
        ans.remove(ans.size() - 1);
    }
    // 判断是否为回文串
    boolean isPalindrome(String str) {
        int left = 0, right = str.length() - 1;
        while (left < right) {
            if (str.charAt(left) != str.charAt(right)) return false;
            left++;
            right--;
        }
        return true;
    }
}
```

- **时间复杂度：O(n·2^n)**

  每个下标只有"切"和"不切"两种选择，一共 2^n 条路径；每条路径上每个切点都要做一次 `substring` + 回文判断，各 O(n)。所以同样是 O(n·2^n)。

- **空间复杂度：O(n)**

  递归深度最多 n 层，当前路径 `ans` 里所有片段的总长度不超过 n。不计返回的结果集。
