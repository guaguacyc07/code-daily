# 74. Kth Largest Element in an Array

- **题目 : [215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)**

> 难度: 中等
>
> 标签: 数组, 分治, 快速选择, 堆

## 解法一

```java
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 大顶堆
        PriorityQueue<Integer> maxHeap = new PriorityQueue<>((a, b) -> b - a);
        for (int i = 0; i < nums.length; i++) {
            // 把数组全部入堆
            maxHeap.offer(nums[i]);
        }
        // 取出第k个最大的元素
        int ret = 0;
        for (int i = 0; i < k; i++) {
            ret = maxHeap.poll();
        }
        return ret;
    }
}
```

- **时间复杂度：O((n + k) log n)**

  把 n 个元素逐个 `offer` 进堆是 O(n log n)；再弹出 k 次，每次 O(log n)。合起来 O((n + k) log n)。

- **空间复杂度：O(n)**

  大顶堆里最多存下全部 n 个元素。
