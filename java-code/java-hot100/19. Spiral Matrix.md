# 19. Spiral Matrix

- **题目 : [54. 螺旋矩阵](https://leetcode.cn/problems/spiral-matrix/)**

> 难度: 中等
>
> 标签: 数组, 矩阵, 模拟

## 解法一

**思路:**

- 用一个boolean的二维数组去存储遍历过的地方 
  - 这一步我觉得可以优化,比如直接复用原数组
  - 比如遍历过的地方直接赋值为Integer.MIN_VALUE (-101也行);
  - 毕竟`-100 <= matrix[i][j] <= 100`
  - 这里就不写优化版了,

- 然后按照顺序遍历即可
  - 但是要注意指针的位置需要调整, 具体看注释...

**AC代码:**

```java
class Solution {
    public List<Integer> spiralOrder(int[][] matrix) {
        List<Integer> ret = new ArrayList<>();
        // 行数
        int m = matrix.length;
        // 列数
        int n = matrix[0].length;

        // 用来标记被遍历过的地方, 防止重复遍历
        boolean[][] flag = new boolean[m][n];
        // i 表示行
        int i = 0;
        // j 表示列
        int j = 0;
        // 记录被遍历过的数据总数
        int sum = 0;

        // 如果没有遍历完全部数据就一直循环
        while(sum < n * m) {
            // 向右遍历
            while(j < n && flag[i][j] == false) {
                flag[i][j] = true;
                ret.add(matrix[i][j]);
                sum++;
                j++;
            }
            // 注意此刻 i 和 j 的位置, 需要调整.
            //(这里的例子只是第一次循环, 后续循环类似情况,只不过不是n - 1了)
            //(可能是 n - 2, n - 3...)
            // 此时 j = n, i = 0 调整为--> j = n - 1, i = 1
            i++;
            j--;
            // 向下遍历
            while(i < m && flag[i][j] == false) {
                flag[i][j] = true;
                ret.add(matrix[i][j]);
                sum++;
                i++;
            }
            // 此处同理, 需要调整 i 和 j
            // {i = m, j = n - 1} --> {i = m - 1, j = n - 2}
            i--;
            j--;
            // 向左遍历
            while(j >= 0 && flag[i][j] == false) {
                flag[i][j] = true;
                ret.add(matrix[i][j]);
                sum++;
                j--;
            }
            // 此处同理, 需要调整 i 和 j
            // {i = m - 1, j = -1} --> {i = m - 2, j = 0}
            i--;
            j++;
            // 向上遍历
            while(i >= 0 && flag[i][j] == false) {
                flag[i][j] = true;
                ret.add(matrix[i][j]);
                sum++;
                i--;
            }
            // 此处同理, 需要调整 i 和 j
            i++;
            j++;
        }
        return ret;
    }
}
```

- **时间复杂度：O(mn)**

  每个格子只会被加入结果一次，四段 `while` 合计正好走完 m×n 个元素。

- **空间复杂度：O(mn)**

  额外开了一个 m×n 的 `flag` 标记数组（就是思路里提到的优化点：复用原数组、把走过的位置改成 `Integer.MIN_VALUE`，就能把额外空间降到 O(1)）。
