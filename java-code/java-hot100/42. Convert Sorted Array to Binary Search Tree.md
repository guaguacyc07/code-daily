# 42. Convert Sorted Array to Binary Search Tree

- **题目 : [108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)**

> 难度: 简单
>
> 标签: 树, 二叉搜索树, 数组, 分治

## 解法一

**思路:**

- 有个小知识点, 二叉树的中序遍历就是一个有序数组
- 对于这题
- 我们可以这么思考
- 先创建一个函数 `TreeNode dfs(int[] nums, int left, int right)`
- 这个函数可以把数组的 `left` 到 `right` 范围变为平衡二叉树
- 取数组中间位置的元素作为**根节点**（这样左右两边元素数量差不多，保证平衡）
- 中间元素左边的子数组，递归构造**左子树**
- 中间元素右边的子数组，递归构造**右子树**
- 递归终止条件：左边界 > 右边界时，返回`null`（没有节点）

```java
class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return dfs(nums, 0 , nums.length - 1);
    }

    TreeNode dfs(int[] nums, int left, int right) {
        if(left > right) return null;

        int mid = (left + right) >> 1;
        TreeNode root = new TreeNode(nums[mid]);
        // 递归数组左边
        root.left = dfs(nums, left, mid - 1);
        // 递归数组右边
        root.right = dfs(nums, mid + 1, right);

        return root;
    }
}
```

- **时间复杂度：O(n)**

  每个元素恰好被用作一次根节点（构造一次）。

- **空间复杂度：O(log n)**

  递归栈深度等于树高；每次取中点保证是平衡树，所以是 O(log n)。
