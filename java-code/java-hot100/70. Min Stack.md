# 70. Min Stack

- **题目 : [155. 最小栈](https://leetcode.cn/problems/min-stack/)**

> 难度: 中等
>
> 标签: 栈, 设计

## 解法一

```java
class MinStack {
    // 用双端队列模拟栈, 然后额外存一个数放在最左边, 这个就是最小值
    // 入栈出栈都从右边, 最左边那个只做记录.
    private Deque<Integer> stack;

    public MinStack() {
        // 初始化栈时往里面放一个最大值
        stack = new ArrayDeque<>();
        stack.offer(Integer.MAX_VALUE);
    }
    
    // 入栈从右边入栈, 每个元素入栈前先和最左边元素(最小值)比较
    // 如果要入栈的值小于等于最小值, 备份当前最小值放到栈体, 方便后续出栈的时候维护最小值
    public void push(int value) {
        // 获取最左边的元素(当前的最小值)
        int curMin = stack.peekFirst();
        if (value <= curMin) {
            // 备份旧最小值到栈体,再更新左端最小值
            stack.offerLast(curMin);
            stack.pollFirst();
            stack.offerFirst(value);
        }
        // 正常压入栈顶
        stack.offerLast(value);
    }
    
    public void pop() {
        // 如果只有一个元素, 直接返回
        if (stack.size() == 1) return;
        int popVal = stack.pollLast();
        // 弹出的是当前最小值, 那么回退到备份的旧最小值
        if (popVal == stack.peekFirst()) {
            stack.pollFirst();
            stack.offerFirst(stack.pollLast());
        }
    }
    
    public int top() {
        return stack.peekLast();
    }
    
    public int getMin() {
        return stack.peekFirst();
    }
}

/**
 * Your MinStack object will be instantiated and called as such:
 * MinStack obj = new MinStack();
 * obj.push(value);
 * obj.pop();
 * int param_3 = obj.top();
 * int param_4 = obj.getMin();
 */
```

- **时间复杂度：O(1)**

  push、pop、top、getMin 都是常数时间：入栈出栈只动双端队列的两端，最小值直接取队首。

- **空间复杂度：O(n)**

  每个元素都会进一次栈体；每当出现新的最小值（≤ 当前最小值）时，还会额外备份一份旧最小值，所以最多存约 2n 个元素，仍是 O(n)。
