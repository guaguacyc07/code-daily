# 21. Search a 2D Matrix II

- **题目 : [240. 搜索二维矩阵 II](https://leetcode.cn/problems/search-a-2d-matrix-ii/)**

> 难度: 中等
>
> 标签: 数组, 二分查找, 分治

## 解法一

> 最开始看到升序, 直接就想到二分了

**思路:**

- 逐行二分即可

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // 行
        int m = matrix.length;
        // 列
        int n = matrix[0].length;
        // 二分
        boolean flag = false;
        for(int i = 0; i < m; i++) {
            // 判断target是否在当前行, 在则进行二分查找
            if(matrix[i][0] <= target && target <= matrix[i][n - 1]) {
                flag = find(matrix[i], target);
                if(flag) return flag;
            }
        }
        return flag;
    }

    public boolean find(int[] arr, int target) {
        int left = 0;
        int right = arr.length - 1;

        while(left <= right) {
            int mid = (left + right) >> 1;
            if(arr[mid] < target) {
                left = mid + 1;
            } else if(arr[mid] > target) {
                right = mid - 1;
            } else {
                return true;
            }
        }
        return false;
    }
}
```

- **时间复杂度：O(m·log n)**

  每行先做一次范围判断（O(1)），命中范围的行再做一次二分查找 O(log n)，共 m 行。

- **空间复杂度：O(1)**

  只用了常数个变量。

## 解法二

**思路:**

- 还有一种非常简单的思路
- 我们从 **右上角** 或者 **左下角** 选择一个作为 **起点** 然后判断大于还是小于 `target` ,逐步逼近即可

- 为什么一定要 **右上角** 或者 **左下角** 呢?
- 因为这俩个地方, 你可以在每次选择中选择 **变大当前数字** 或 **变小当前数字**

- 这便是关键

```java
class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        // 行
        int m = matrix.length;
        // 列
        int n = matrix[0].length;

        int i = 0;
        int j = n - 1;
        // 从右上角开始遍历
        while(i < m && 0 <= j) {
            if(matrix[i][j] < target) i++;
            else if(matrix[i][j] > target) j--;
            else return true; 
        }
        return false;
    }
}
```

- **时间复杂度：O(m + n)**

  每走一步要么 `i++`（往下）要么 `j--`（往左），最多向下 m 次 + 向左 n 次。

- **空间复杂度：O(1)**

  只用了 i、j 两个变量。
