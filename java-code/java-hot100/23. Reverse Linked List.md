# 23. Reverse Linked List

- **题目 : [206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)**

> 难度: 简单
>
> 标签: 递归, 链表

## 解法一(递归)

**思路:**

- 递归里面只干了一件事, 把当前节点的下个节点指向当前节点, 然后当前节点指向null
- 要注意的是`ListNode newhead = dfs(head.next);`和`return newhead;`
- 这里永远返回的都是最后的那个节点, 可以拿草稿纸演算一下
- 所以主要递归干的就只有一件事
- 至于当前节点指向空这一步很关键  ---- 他可以保证最后遍历到的节点指向空(也就是原先的头节点)
- 不然不就成环了吗?

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        return dfs(head);
    }
    ListNode dfs(ListNode head) {
        if(head == null || head.next == null) return head;
        // 先反转后面的节点，从后往前反转
        // newhead永远是最后的那个节点
        ListNode newhead = dfs(head.next);
        
        // 下个节点指向自己，自己指向空
        head.next.next = head;
        head.next = null;
        
        return newhead;
    }
}
```

- **时间复杂度：O(n)**

  每个节点只被处理一次。

- **空间复杂度：O(n)**

  递归栈深度为链表长度 n。

## 解法二(迭代)

```java
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode pre = null;
        ListNode cur = head;
        
        // 从头往后
        while(cur != null) {
            ListNode nxt = cur.next;

            cur.next = pre;
            pre = cur;
            cur = nxt;
        }
        return pre;
    }
}
```

- **时间复杂度：O(n)**

  一趟遍历，每个节点只改一次指针。

- **空间复杂度：O(1)**

  只用了 pre、cur、nxt 三个指针。
