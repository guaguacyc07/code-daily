**AC代码:**

```java
class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 当前节点是空节点, p, q 都返回当前节点
        if(root == null || root == p || root == q) return root;

        // 寻找左右子树是否有 p 或者 q
        TreeNode left = lowestCommonAncestor(root.left, p, q);
        TreeNode right = lowestCommonAncestor(root.right, p, q);

        // 如果左右子树都没找到(left == null && right == null), 返回空节点
        // if(left == null || right == null) return null;
        // 很明显, 这句代码的其实已经蕴含在了下面那两句代码之中, 可以好好体会一下

        // 只有左子树找到(右子树为null), 返回递归左子树的结果
        if(right == null) return left;
        // 只有右子树找到(左子树为null), 返回递归右子树的结果
        if(left == null) return right;

        // 左右子树都找到了(left != null && right != null), 返回当前节点(root)
        return root;
    }
}
```

- **时间复杂度：O(n)**

  最坏情况要访问每个节点一次（p、q 都在树里，找到就提前返回）。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h（平衡树 O(log n)，链状树 O(n)）。
