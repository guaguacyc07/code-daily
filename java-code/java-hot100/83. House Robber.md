# 83. House Robber

- **题目 : [198. 打家劫舍](https://leetcode.cn/problems/house-robber/)**

> 难度: 中等
>
> 标签: 数组, 动态规划

## 解法一

```java
class Solution {
    public int rob(int[] nums) {
        // 对于当前房间, 可以选择偷或者不偷
        // dp[i] = max(dp[i - 1], dp[i] + nums[i])
        if (nums.length == 0) return 0;

        int n = nums.length;
        int[] dp = new int[n + 1];

        dp[0] = 0;
        dp[1] = nums[0];

        for (int i = 1; i < n; i++) {
            dp[i + 1] = Math.max(dp[i], dp[i - 1] + nums[i]);
        }
        return dp[n];
    }
}
```

- **时间复杂度：O(n)**

  从第 2 个房间递推到第 n 个，每一步 O(1)。

- **空间复杂度：O(n)**

  `dp` 数组开了 n + 1 个位置；每项只依赖前两项，其实可以滚成两个变量做到 O(1)。
