# 69. Valid Parentheses

- **题目 : [20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)**

> 难度: 简单
>
> 标签: 栈, 字符串

## 解法一

```java
class Solution {
    public boolean isValid(String s) {
        // 双端队列模拟栈
        Deque<Character> stack = new ArrayDeque<>();
        // 没有遇到右括号前就一直往栈里加元素
        // 如果遇到右括号, 那么先判断当前栈顶是不是对应的左括号
        // 1. 如果是, 那么移除当前堆顶, 继续判断下个括号
        // 2. 如果不是, 返回false
        for (int i = 0; i < s.length(); i++) {
            // 获取当前遍历到的括号
            char ch = s.charAt(i);
            // 先判断是否为右括号
            if (ch == ')' || ch == ']' || ch == '}') {
                // 空栈遇到右括号,直接不合法,先判空再取元素,避免空指针
                if (stack.isEmpty()) {
                    return false;
                }
                // 移出栈顶元素, 并判断是否是对应的左括号
                char last = stack.pollLast();
                if (ch == ')' && last != '(') return false;
                if (ch == ']' && last != '[') return false;
                if (ch == '}' && last != '{') return false;
            } else {
                // 不是右括号加加进去
                stack.offer(ch);
            }  
        }
        // 判断栈是否为空, 如果为空则返回true, 否则返回false
        if (stack.isEmpty()) {
            return true;
        } else {    
            return false;
        }
    }
}
```

- **时间复杂度：O(n)**

  只扫一遍字符串，每个字符要么入栈、要么出栈一次。

- **空间复杂度：O(n)**

  最坏情况（比如全是左括号）栈里要存下 n 个字符。
