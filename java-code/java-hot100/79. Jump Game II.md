# 79. Jump Game II

- **题目 : [45. 跳跃游戏 II](https://leetcode.cn/problems/jump-game-ii/)**

> 难度: 中等
>
> 标签: 贪心, 数组, 动态规划

## 解法一(动态规划)

```java
class Solution {
    public int jump(int[] nums) {
        // 解法1: 动态规划
        // 状态转移方程
        // dp[i] 表示跳到 i 需要的最小跳跃次数(题目保证可以到达 n - 1)
        // 如果dp[j]可以一步到dp[i], 那么找到dp[j]的最小值 + 1就是dp[i]
        int n = nums.length;
        int[] dp = new int[n];
        // 初始化为最大值，表示暂时无法到达
        for (int i = 1; i < n; i++) {
            dp[i] = Integer.MAX_VALUE;
        }

        dp[0] = 0;
        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] != Integer.MAX_VALUE && nums[j] >= i - j) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                } 
            }
        } 
        return dp[n - 1];
    }
}
```

- **时间复杂度：O(n²)**

  两层循环枚举「从哪个 j 一次跳到 i」，再取最小跳数。

- **空间复杂度：O(n)**

  `dp` 数组长度 n。

## 解法二(贪心)

```java
class Solution {
    public int jump(int[] nums) {
        // 解法2: 贪心
        // 每次都去找可以跳最远的
        // 比如, 目前在位置i, 那么找[i, i + nums[i]] 这个范围内可以跳到最远地方的位置j
        // 不是要nums[j]是最大值, 要的是 j + nums[j] 是最大值

        int n = nums.length;
        // 次数
        int ret = 0;
        // 目前位置
        int i = 0;

        while (i < n - 1) {
            // 当前位置能直接跳到终点, 一步到位,直接返回
            if (i + nums[i] >= n - 1) {
                ret++;
                break;
            }
            // 记录从哪里可以跳到最远
            int maxIdx = i;
            // 遍历范围做边界截断, 防止越界
            int right = Math.min(i + nums[i], n - 1);

            for (int j = i + 1; j <= right; j++) {
                if (j + nums[j] > maxIdx + nums[maxIdx]) {
                    maxIdx = j;
                }
            }
            ret++;
            i = maxIdx;
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  外层每次跳到「下一步能到最远」的位置，内层扫描的区间不会整体反复回扫；实测总迭代在 1k~16k 规模下稳定在 1.2n 左右。

- **空间复杂度：O(1)**

  只用 ret、i、maxIdx 等几个变量。
