# 77. Best Time to Buy and Sell Stock

- **题目 : [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)**

> 难度: 简单
>
> 标签: 数组, 动态规划

## 解法一

```java
class Solution {
    public int maxProfit(int[] prices) {
        // 如果数组长度小于等于1, 直接返回
        int n = prices.length;
        if (n <= 1) return 0;

        // ret为返回值, pmin表示prices[i]前的最小值
        int ret = 0;
        int pmin = prices[0];

        for (int i = 0; i < n; i++) {
            // 把ret和当前的值减去最小值作比较
            ret = Math.max(ret, prices[i] - pmin);
            // 更新当前的最小值
            pmin = Math.min(pmin, prices[i]);
        }

        return ret;
    }
}
```

- **时间复杂度：O(n)**

  只扫一遍数组，边扫边维护「到今天为止的最小价格」。

- **空间复杂度：O(1)**

  只用了 ret、pmin 两个变量。
