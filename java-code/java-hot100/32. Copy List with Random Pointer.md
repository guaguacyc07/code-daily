# 32. Copy List with Random Pointer

- **题目 : [138. 随机链表的复制](https://leetcode.cn/problems/copy-list-with-random-pointer/)**

> 难度: 中等
>
> 标签: 哈希表, 链表

## 解法一

**思路**

<img src="./img/32.%20Copy%20List%20with%20Random%20Pointer.assets/image-20260920214347869.png" alt="image-20260920214347869" style="zoom: 67%;" />

假设上面这个图是我们要复制的原链表

- 我们的主要问题是如何复制到他的随机节点 `random` ?
- 那么我们可以一步一步来思考...
- 首先, 我们要想复制到随机节点 `random` , 那么我们肯定要先复制出一个链表 (这个复制的链表可以先不给 `random` 值) , 这样才能保证 `random` 指向的节点存在于我们复制的链表中
- 那么问题又来了, 我们就算复制出来了一个新的链表, 可是我们不可能直接用原链表的 `random` 吧 ?
- 毕竟那指向原链表, 和我们的复制链表没半毛钱关系...
- 那么能不能使得原链表和复制链表产生关系呢? 而这种关系刚好可以利用到原链表的 `random`呢?

<img src="./img/32.%20Copy%20List%20with%20Random%20Pointer.assets/image-20260920215337916.png" alt="image-20260920215337916" style="zoom:67%;" />



如图

- 我们可以在原链表的每个节点后面多增加一个复制节点
- 仔细观察关系
- 你会发现 `复制节点的random值` = `原节点的random值的next` 

- 这样我们就将原链表的 `random` 利用起来了
- 将复制链表每个节点的 `random` 值赋好后, 我们把原链表和复制链表拆开就行了

怎么拆开?

- 这就简单了, 这里具体看我代码吧

**AC代码:**

```java
class Solution {
    public Node copyRandomList(Node head) {
        if(head == null) return null;
        // 用哑节点记录head
        Node tempHead = head;

        // 在原链表每个节点后插入一个复制节点
        while(head != null) {
            Node temp = head.next;
            head.next = new Node(head.val);
            head.next.next = temp;
            // head指向原先的下一个节点
            head = temp;
        }
        // 还原头节点
        head = tempHead;

        // 处理随机节点
        while(head != null) {
            if(head.random == null) {
                head.next.random = null;
            } else {
                head.next.random = head.random.next;
            }
            head = head.next.next;
        }
        // 还原头节点
        head = tempHead;
        
        // 用一个空节点指向复制链表的头节点
        Node ret = head.next;

        // 分离链表
        while(head.next != null) {
            Node copy = head.next;
            head.next = head.next.next;
            head = copy;
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  三趟线性遍历：交错插入复制节点、处理 `random`、拆分两条链表。

- **空间复杂度：O(1)**

  除了必须返回的复制链表本身，只用了常数个指针——这就是它比"哈希表存 原节点→复制节点"（O(n) 空间）更优的地方。
