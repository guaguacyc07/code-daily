# 37. Maximum Depth of Binary Tree

- **题目 : [104. 二叉树的最大深度](https://leetcode.cn/problems/maximum-depth-of-binary-tree/)**

> 难度: 简单
>
> 标签: 树, 深度优先搜索, 广度优先搜索

## 解法一(dfs)

> 这里就只讲dfs思路了,bfs只放代码

思路:

- 递归只管结果, 所以 `maxDepth` 这个函数会返回以当前节点为根节点的最大深度
- 然后先分别找出左右子树最大值
- 然后直接返回最大值加 1
- 为什么加 1 呢?
- 因为递归从最深处往浅

**AC代码:**

```java
class Solution {
    public int maxDepth(TreeNode root) {
        if(root == null) return 0;
        // 找左子树最大值
        int leftMax = maxDepth(root.left);
        // 找右子树最大值
        int rightMax = maxDepth(root.right);
        // 返回左右子树的最大值 + 1
        return Math.max(leftMax, rightMax) + 1;
    }
}
```

- **时间复杂度：O(n)**

  每个节点恰好被访问一次。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h：平衡树是 O(log n)，最坏（链状树）是 O(n)。

## 解法二(bfs)

```java
class Solution {
    public int maxDepth(TreeNode root) {
        //广度优先
        if (root == null) return 0;
        //初始化队列
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int ans = 0;

        while (!queue.isEmpty()) {
            int size = queue.size();
            while (size > 0) {
                TreeNode node = queue.poll();
                if (node.left != null) {
                    queue.offer(node.left);
                }
                if (node.right != null) {
                    queue.offer(node.right);
                }
                size--;
            }
            ans++;
        }
        return ans;
    }
}
```

- **时间复杂度：O(n)**

  每个节点入队、出队各一次。

- **空间复杂度：O(w)**

  队列里最多同时存一层的节点，w 为树的最大宽度（完全二叉树最宽约 n/2，最坏 O(n)）。
