# 66. Search in Rotated Sorted Array

- **题目 : [33. 搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/)**

> 难度: 中等
>
> 标签: 数组, 二分查找

## 解法一(两次二分)

写这题前, 可以先看看后面那道**[153. 寻找旋转排序数组中的最小值](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)**

也许会给到一些启发

```java
class Solution {
    public int search(int[] nums, int target) {
        int n = nums.length - 1;
        int idx = findMinIdx(nums, 0, n);

        // idx所代表的值是右半部分的最小值
        // 如果最右边的值小于target, 那么说明target可能在[0, idx - 1]中
        if (nums[n] < target) {
            return findTarget(nums, target, 0, idx - 1);
        }
        // 否则,那就是可能在[idx, n]中
        return findTarget(nums, target, idx, n);

    }
    // 找到最小值的下标
    int findMinIdx(int[] nums, int left, int right) {
        // 记录最右边的值
        int n = right;
        while (left < right) {   // 结束条件 left == right
            int mid = (left + right) >>> 1;
            // 如果当前mid的值大于最右边的值
            if (nums[mid] > nums[n]) {
                left = mid + 1;
            } else {
                // mid在右半部分时, 最小值可能是 mid 本身
                right = mid;
            }
        }
        // 此处返回left或right都可
        return left;
    }
    // 标准二分
    int findTarget(int[] nums, int target, int left, int right) {
        while (left < right) {
            int mid = (left + right) >>> 1;
            if (nums[mid] < target) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        return target == nums[left] ? left : -1; 
    }

}
```

- **时间复杂度：O(log n)**

  两次二分：`findMinIdx` 先 O(log n) 找到最小值下标，`findTarget` 再在对应的一段里 O(log n) 找 target。

- **空间复杂度：O(1)**

  只用了 left、right、mid、idx 几个变量。



## 解法二(一次二分)

```java
class Solution {
    public int search(int[] nums, int target) {
        int n = nums.length - 1; 
        int left = 0, right = n;
        while (left < right) {
            int mid = (left + right) >>> 1;
            // 如果 target > nums[n] >= nums[mid] 
            // 说明target在左半部分,且在nums[mid]的左边
            if (target > nums[n] && nums[n] >= nums[mid]) {
                right = mid;
            // 如果 nums[mid] > nums[n] >= target
            // 说明target在右半部分, 且在nums[mid]的右边
            } else if (nums[mid] > nums[n] && nums[n] >= target) {
                left = mid + 1;
            // 否则, 只有一种大分组(target和nums[mid]在同一侧)
            // 所以只需要分析target和nums[mid]二者大小即可
            } else if (target > nums[mid]) {
                left = mid + 1;
            } else {
                right = mid;
            }
        }
        // 循环结束条件 left == right
        return target == nums[right] ? right : -1;
    }
}
```

- **时间复杂度：O(log n)**

  只做一次二分，每次区间减半。

- **空间复杂度：O(1)**

  只用了 left、right、mid 三个变量。
