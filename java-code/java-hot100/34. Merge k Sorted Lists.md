# 34. Merge k Sorted Lists

- **题目 : [23. 合并 K 个升序链表](https://leetcode.cn/problems/merge-k-sorted-lists/)**

> 难度: 困难
>
> 标签: 链表, 分治, 堆

## 解法一

最最最简单的思路: 顺序合并

前情提要: **[21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)**

直接遍历一遍 **`lists`** 然后一个一个合并就行了

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {
        if(lists.length == 0) return null;
        ListNode ret = lists[0];
        for(int i = 1; i < lists.length; i++) {
            ret = merge(ret, lists[i]);
        }
        return ret;
    }
    ListNode merge(ListNode list1, ListNode list2) {
        ListNode ans = new ListNode(-1);
        ListNode ret = ans;
        
        while(list1 != null && list2 != null) {
            if(list1.val <= list2.val) {
                ans.next = list1;
                list1 = list1.next;
            } else {
                ans.next = list2;
                list2 = list2.next;
            }
                ans = ans.next;
        }
        if(list1 == null) ans.next = list2;
        if(list2 == null) ans.next = list1;
         
         return ret.next;
    }
}
```

- **时间复杂度：O(N·k)**

  N 是所有链表的节点总数、k 是链表条数：第 i 次合并时，前面已经合出来的结果又会被完整走一遍，最坏情况下（每次只挂上很短的链表）累计是 O(N·k)。

- **空间复杂度：O(1)**

  只用哨兵节点和几个指针，合并在原节点上进行（不计输出链表本身）。

## 解法二

分治递归

> 用迭代空间可以降到O(1)

**思路:**

- 只需要管递归的结果和出口就行, 不要去在意过程
- 这里我的递归函数是左闭右开, 所以用 `rightIdx - leftIdx` 去计算 **区间元素**

**AC代码:**

```java
class Solution {
    public ListNode mergeKLists(ListNode[] lists) {                         
        return mergeKLists(lists, 0, lists.length);
    }
    // 合并从 leftIdx 到 rightIdx 的链表
    ListNode mergeKLists(ListNode[] lists, int leftIdx, int rightIdx) {
        // 左闭右开，算区间内元素
        int len = rightIdx - leftIdx;
        if(len == 0) return null;
        if(len == 1) return lists[leftIdx];
        
        ListNode leftList = mergeKLists(lists, leftIdx, leftIdx + len / 2);
        ListNode rightList = mergeKLists(lists, leftIdx + len / 2, rightIdx);
        return merge(leftList, rightList);
    }
          
    ListNode merge(ListNode list1, ListNode list2) {
        ListNode ans = new ListNode(-1);
        ListNode ret = ans;
        
        while(list1 != null && list2 != null) {
            if(list1.val <= list2.val) {
                ans.next = list1;
                list1 = list1.next;
            } else {
                ans.next = list2;
                list2 = list2.next;
            }
                ans = ans.next;
        }
        if(list1 == null) ans.next = list2;
        if(list2 == null) ans.next = list1;
         
         return ret.next;
    }
}
```

- **时间复杂度：O(N·log k)**

  每次把 k 条链表二分（共 log k 层），每一层所有节点合计被合并一次，合计 O(N·log k)。

- **空间复杂度：O(log k)**

  递归栈深度为 log k（改写成自底向上的迭代分治即可降到 O(1)，也就是上面备注说的优化）。
