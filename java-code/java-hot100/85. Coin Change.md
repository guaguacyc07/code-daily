# 85. Coin Change

- **题目 : [322. 零钱兑换](https://leetcode.cn/problems/coin-change/)**

> 难度: 中等
>
> 标签: 广度优先搜索, 数组, 动态规划

## 解法一

> 这种类型的题目, 某些情况下可以用贪心,但是这里很明显故意做了一些数值上的限制,不让你用贪心

```java
class Solution {
    public int coinChange(int[] coins, int amount) {
        // dp[i] 表示凑成i元需要的最少硬币数量
        // 最多全是1元硬币, 所以数组开amount + 1就行
        int[] dp = new int[amount + 1];

        // 给数组初始化: 找最小值,所以我们先全部给最大值,方便用min
        Arrays.fill(dp, amount + 1);

        dp[0] = 0;

        // 每个金额都有选或不选这个选择
        // 对于i - coins[j], 表示选了coins[j]后还需要凑的钱数
        // 要注意 i 和 coins[j]的大小
        for (int i = 1; i <= amount; i++) {
            for (int j = 0; j < coins.length; j++) {
                if (i >= coins[j]) dp[i] = Math.min(dp[i], dp[i - coins[j]] + 1);
            }
        }
        // 如果凑不出来, 那就返回 -1
        return dp[amount] > amount ? -1 : dp[amount];
    }
}
```

- **时间复杂度：O(amount × coins.length)**

  外层枚举金额 1 到 amount，内层枚举每种硬币。

- **空间复杂度：O(amount)**

  `dp` 数组长度 amount + 1。
