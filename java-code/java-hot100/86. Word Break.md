# 86. Word Break

- **题目 : [139. 单词拆分](https://leetcode.cn/problems/word-break/)**

> 难度: 中等
>
> 标签: 字典树, 记忆化搜索, 数组, 动态规划

## 解法一

```java
class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        // dp[i]表示, s[0]到s[i - 1]是否可以分为若干个字典里出现的单词

        // 用set集合,方便用contains查
        Set<String> set = new HashSet<>(wordDict);
        boolean[] dp = new boolean[s.length() + 1];
        dp[0] = true;

        // 对于0 到 i-1, 需要去枚举每个切割点j
        // 判断j到i-1是否也属于字典
        // 而对于0到j, 看dp[j]就行了

        for (int i = 0; i <= s.length(); i++) {
            for (int j = 0; j < i; j++) {
                if (dp[j] && set.contains(s.substring(j, i))) {
                    dp[i] = true;
                    // 找到一种可拆方案就可以返回了
                    break;
                }
            }
        }
        return dp[s.length()];
    }
}
```

- **时间复杂度：O(n³)**

  n 为 s 的长度。两层循环本身是 O(n²)，但每次还要 `substring` 新建一个长度最多 n 的子串再计算哈希，这一步 O(n)，所以上界是 O(n³)。本题 n ≤ 300，完全够用。

- **空间复杂度：O(n + Σ|word|)**

  `dp` 数组 O(n)，哈希表里存字典所有单词的字符。
