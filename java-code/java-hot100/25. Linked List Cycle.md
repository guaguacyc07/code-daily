# 25. Linked List Cycle

- **题目 : [141. 环形链表](https://leetcode.cn/problems/linked-list-cycle/)**

> 难度: 简单
>
> 标签: 哈希表, 链表, 双指针

## 解法一

> 有点龟兔赛跑的感觉, 只不过这里兔子没睡觉, 直接给乌龟套圈了

**思路:**

- 我们整俩指针, `slow` 和 `fast`
- `slow` 指针每次移动一步, `fast` 每次移动两步
- 只要存在环, 那么 `slow` 和 `fast` 一定会接触到

为什么? 下面给出例子

> 默认slow先走

- 无环不讨论, 无环fast肯定先到null
- 这里会给你举出俩种情况, 分析slow和fast只要有环一定会相遇

> 接下来是第一种情况	

![image-20260917212038056](./img/25.%20Linked%20List%20Cycle.assets/image-20260917212038056.png)

- 对于第一种情况
  - `slow`先走一步, 到达 **5** , `fast`走两步, 到达 **4**
  - 然后接着, `slow`再走一步, 到达 **6** , `fast` 走两步, 也到达 **6** , 两个指针重合, `return true`

> 接下来是第二种情况		

![image-20260917212441571](./img/25.%20Linked%20List%20Cycle.assets/image-20260917212441571.png)

- 对于第二种情况
  - `slow`先走一步, 到达 **4** , `fast`走两步, 到达 **4** ,  两个指针重合, `return true`

**AC代码:**

```java
public class Solution {
    public boolean hasCycle(ListNode head) {
        if(head == null || head.next == null) return false;

        ListNode slow = head;
        ListNode fast = head;

        while(fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if(slow == fast) return true;
        }
        return false;
    }
}
```

- **时间复杂度：O(n)**

  无环时 `fast` 先走到 null（最多 n/2 步）；有环时 `slow`、`fast` 进入环后一定在 O(n) 步内相遇。

- **空间复杂度：O(1)**

  只用了 `slow`、`fast` 两个指针——这正是它比"哈希表存已访问节点"（O(n) 空间）更优的地方。
