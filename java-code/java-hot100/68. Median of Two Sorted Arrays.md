# 68. Median of Two Sorted Arrays

- **题目 : [4. 寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)**

> 难度: 困难
>
> 标签: 数组, 二分查找, 分治

## 解法一

```java
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        int m = nums1.length; // nums1的数组长度
        int n = nums2.length; // nums2的数组长度
        int sum = m + n;      // 合并数组的元素总数

        // 保证nums1是更短的数组，避免idx越界，同时二分效率最高
        if (m > n) {
            int[] temp = nums1;
            nums1 = nums2;
            nums2 = temp;
            int tmpLen = m;
            m = n;
            n = tmpLen;
        }

        // 对nums1和nums2进行切割, 需要让其满足以下条件
        // 1.如果总数是奇数个: 那么nums1和nums2切割出来的左半部分要大于右半部分1个数
        // 这样就可以使得当切割正确时,左半部分的最大值就是中值
        // 2.如果总数是偶数个: 那么nums1和nums2切割出来的左半部分和右半部分相同个数
        // 这样取左半部分的最大值和右半部分的最小值加起来除以2即可
        // 3.nums1切出来的左半部分的最大值要小于nums2切出来的右半部分的最小值
        // 4.nums2切出来的左半部分的最大值要小于nums1切出来的右半部分的最小值
        
        // 当我们切割好nums1后, 那么nums2的切割位置将会是固定的
        // nums2 -- [0, (sum + 1)/2-nums1左半部分的元素个数] [nums2的右半部分]
        // ps: 这里向上取整是为了满足条件1

        // 从nums1中切一刀, 要怎么切? 用二分的方法去切
        // left初始为-1，支持nums1左半0个元素的边界场景
        int left = -1, right = m - 1;
        while(left < right) {
            // 这里的mid本质上就是左半部分数组的最后一个数的索引
            // 上取整，避免二分死循环
            int mid = (left + right + 1) >>> 1;
            // 计算nums2右半部分第一个元素的索引
            // (mid+1)是nums1左半边元素个数，idx = 总左半元素数 - nums1左半元素数
            int idx = (sum + 1) / 2 - (mid + 1); 

            // 不满足条件3: nums1左半太大, 往左收缩右边界
            // 越界判断: idx==n时nums2右半无元素,视为无穷大,不会触发此条件
            if (idx < n && nums1[mid] >= nums2[idx]) {
                right = mid - 1;
            // 不满足条件4: nums1左半太小,往右扩大左边界
            // 越界判断: idx==0时nums2左半无元素,视为无穷小
            // mid==m-1时nums1右半无元素,视为无穷大,都不会触发此条件
            } else if (idx > 0 && mid < m - 1 && nums2[idx - 1] >= nums1[mid + 1]) {
                left = mid + 1;
            // 两个条件都满足,找到合法切割点
            } else {
                left = mid;
                break;
            }
        }

        // 循环结束,left就是最终的切割点mid
        int mid = left;
        int idx = (sum + 1) / 2 - (mid + 1);

        // 统一处理边界越界,计算四个关键值
        int nums1LeftMax = mid == -1 ? Integer.MIN_VALUE : nums1[mid];
        int nums1RightMin = mid == m - 1 ? Integer.MAX_VALUE : nums1[mid + 1];
        int nums2LeftMax = idx == 0 ? Integer.MIN_VALUE : nums2[idx - 1];
        int nums2RightMin = idx == n ? Integer.MAX_VALUE : nums2[idx];

        // 计算中位数
        if (sum % 2 == 1) {
            // 如果是奇数, 返回左半部分的最大值
            return Math.max(nums1LeftMax, nums2LeftMax);
        } else {
            // 如果是偶数,返回左半部分的最大值和右半部分的最小值之和除以2
            return (Math.max(nums1LeftMax, nums2LeftMax) + Math.min(nums1RightMin, nums2RightMin)) / 2.0;
        }
    }
}

```

- **时间复杂度：O(log min(m, n))**

  先把较短的数组换到 nums1，然后只在 nums1 上二分切割点，二分范围是 min(m, n)；nums2 的切割点由总数直接算出来，O(1)。所以是 O(log min(m, n))。

- **空间复杂度：O(1)**

  只用了 left、right、mid、idx 和四个边界值。
