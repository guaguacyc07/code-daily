# 27. Merge Two Sorted Lists

- **题目 : [21. 合并两个有序链表](https://leetcode.cn/problems/merge-two-sorted-lists/)**

> 难度: 简单
>
> 标签: 递归, 链表

## 解法一

> 依旧画图给出思路

![image-20260919212033529](./img/27.%20Merge%20Two%20Sorted%20Lists.assets/image-20260919212033529.png)

循环条件定为 `list1 != null && list2 != null` 

每次循环中, 如果 `list1.val <= list2.val`, 那么就把 `ret` 指向 `list1` ( 反之则指向 `list2` )

然后 `list1` 后移 ( `list2` 后移)

`ret` 也要后移, 当存在一个到达 `null` 时, 把剩下那个后面全部拼接过去就行了

**AC代码:**

```java
class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if(list1 == null) return list2;
        if(list2 == null) return list1;
        ListNode ret = new ListNode();
        ListNode ans = ret;

        while(list1 != null && list2 != null) {
            if(list1.val <= list2.val) {
                ret.next = list1;            
                list1 = list1.next;
            } else {
                ret.next = list2;
                list2 = list2.next;   
            }
            ret = ret.next;
        }

        if(list1 == null) ret.next = list2;
        else ret.next = list1; 

        return ans.next;
    }
}
```

- **时间复杂度：O(m + n)**

  两个链表各遍历一遍，每个节点只被接一次。

- **空间复杂度：O(1)**

  只用了一个哨兵节点和几个指针，合并过程直接复用原节点，没有新建链表。
