# 44. Kth Smallest Element in a BST

- **题目 : [230. 二叉搜索树中第K小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)**

> 难度: 中等
>
> 标签: 树, 深度优先搜索, 二叉搜索树

## 解法一

**思路:**

- **中序遍历的结果是有序的**
- 中序遍历到第k个就返回结果就行了

**AC代码:**

```java
class Solution {
    int count;
    int ret;
    public int kthSmallest(TreeNode root, int k) {
        count = k;
        dfs(root);
        return ret;
    }
    // 中序遍历
    void dfs(TreeNode root) {
        if(root == null) return;

        // 遍历左子树
        dfs(root.left);

        count--;
        if(count == 0) ret = root.val;

        // 遍历右子树
        dfs(root.right);
    }
}
```

- **时间复杂度：O(n)**

  当前写法找到第 k 个后**没有提前返回**，中序遍历仍会把整棵树走完（结果是对的，但少了个剪枝）。

  > 💡 若在 `dfs` 开头加 `if(count <= 0) return;`（或找到后直接 return），就能提前终止，最坏也只是 O(h + k)。

- **空间复杂度：O(h)**

  递归栈深度等于树高 h（平衡树 O(log n)，链状树 O(n)）。
