# 72. Daily Temperatures

- **题目 : [739. 每日温度](https://leetcode.cn/problems/daily-temperatures/)**

> 难度: 中等
>
> 标签: 栈, 数组, 单调栈

## 解法一

```java
class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        // 栈中记录下一个更大元素的[候选项]的下标
        // 每次循环, 我们可以在[候选项]中找到答案
        int n = temperatures.length;
        int[] ret = new int[n];
        Deque<Integer> stack = new ArrayDeque<>();

        // 从右往左
        for (int i = n - 1; i >= 0; i--) {
            // 获取当前遍历到的温度
            int t = temperatures[i];
            // 只要栈有数据, 且栈顶元素小于等于当前温度,就循环出栈,直到大于当前温度
            while (!stack.isEmpty() && t >= temperatures[stack.peek()]) stack.pop();
            // 如果此时栈里有元素, 那么就说明当前栈顶的元素就是在索引后第一个更高的温度的索引
            if (!stack.isEmpty()) ret[i] = stack.peek() - i;
            // 最后, 把当前索引加进栈
            stack.push(i);
        }
        return ret;
    }
}
```

- **时间复杂度：O(n)**

  每个下标最多入栈一次、出栈一次，所以整个循环是线性的（n 为温度数组长度）。

- **空间复杂度：O(n)**

  单调栈最坏（温度单调递增）会存下所有下标。
