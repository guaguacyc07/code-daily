# 82. Pascal's Triangle

- **题目 : [118. 杨辉三角](https://leetcode.cn/problems/pascals-triangle/)**

> 难度: 简单
>
> 标签: 数组, 动态规划

## 解法一

```java
class Solution {
    public List<List<Integer>> generate(int numRows) {
        List<List<Integer>> ret = new ArrayList<>();
        
        // 第一层为1
        if (numRows >= 1) {
            List<Integer> row = new ArrayList<>();
            row.add(1);
            ret.add(row);
        }
        // 第二层为 1, 1
        if (numRows >= 2) {
            List<Integer> row = new ArrayList<>();
            row.add(1);
            row.add(1);
            ret.add(row);
        }
        // 第三层及后续层
        for (int i = 3; i <= numRows; i++) {
            List<Integer> row = new ArrayList<>();
            // 最左边和最右边都是1
            row.add(1);
            // 中间元素：上一行的 j-1 和 j 位置相加
            // 第i行有i个元素，中间共 i-2 个，j从1遍历到 i-2
            for (int j = 1; j < i - 1; j++) {
                int left = ret.get(i - 2).get(j - 1);
                int right = ret.get(i - 2).get(j);
                row.add(left + right);
            }
            row.add(1);
            ret.add(row);
        }
        return ret;
    }
}
```

- **时间复杂度：O(numRows²)**

  一共生成 1 + 2 + ... + numRows 个数字，约 numRows²/2 个。

- **空间复杂度：O(numRows²)**

  返回的二维列表本身就要存这么多数字；不计返回值的话，额外空间只有当前行和几个变量，是 O(numRows)。
