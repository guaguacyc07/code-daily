# 26. Linked List Cycle II

- **题目 : [142. 环形链表 II](https://leetcode.cn/problems/linked-list-cycle-ii/)**

> 难度: 中等
>
> 标签: 哈希表, 链表, 双指针

## 解法一

![image-20260918110158333](./img/26.%20Linked%20List%20Cycle%20II.assets/image-20260918110158333.png)

**思路:**

- 从 **环起始点** 到 **相遇点** 的距离为 **`b - a`** , 也就是 **`ck - a`** 所以再走 **a** 步便刚好走完一个环, 回到 **环起始点**

- 所以你会发现
  - 从 **head** 到 **环起始点** 的距离是 **a**
  - 而从 **相遇点** 到 **环起始点** 的距离也是 **a**
- 因此, 只要 **head** 和 **slow** 相遇的时候, 那就是**环起始点**

**AC代码:**

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        if(head == null || head.next == null) return null;

        ListNode slow = head;
        ListNode fast = head;

        while(fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if(slow == fast) break;
        }
        if(fast != slow) return null;

        while(slow != head) {
            slow = slow.next;
            head = head.next;
        }
        return slow;
    }
}
```

- **时间复杂度：O(n)**

  第一阶段 `slow`/`fast` 最多走 O(a + c) 步判断有无环；第二阶段 `head`、`slow` 再各走 a 步，整体仍是线性。

- **空间复杂度：O(1)**

  只用了 `slow`、`fast` 两个指针。

- 这里还可以有另一种写法, 思路一样, 代码更简洁

**AC代码:**

```java
public class Solution {
    public ListNode detectCycle(ListNode head) {
        if(head == null || head.next == null) return null;

        ListNode slow = head;
        ListNode fast = head;

        while(fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
            if(slow == fast) {
                while(slow != head) {
                    slow = slow.next;
                    head = head.next; 
                }
                return slow;
            }
        }
        return null;
    }
}
```

- **时间复杂度：O(n)**、**空间复杂度：O(1)**

  与上一种写法完全同一个算法，只是把「找入环点」并进了检测到环的分支里。
