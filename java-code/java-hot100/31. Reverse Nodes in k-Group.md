# 31. Reverse Nodes in k-Group

- **题目 : [25. K 个一组翻转链表](https://leetcode.cn/problems/reverse-nodes-in-k-group/)**

> 难度: 困难
>
> 标签: 递归, 链表

## 解法一

前情提要 -- **[206. 反转链表](https://leetcode.cn/problems/reverse-linked-list/)**

只要理清几个重要变量, 这题并没有难度

1. 当前翻转组的第一个节点的前一个节点 `pre`
2. 当前翻转组的最后一个节点 `end`
3. 前翻转组的第一个节点 `fir`
4. 下个翻转组的第一个节点 `nxtFir`

**AC代码:**

```java
class Solution {
    public ListNode reverseKGroup(ListNode head, int k) {
        if(k == 1 || head.next == null) return head;

        // pre记录的是当前翻转组的第一个节点的前一个节点
        ListNode pre = new ListNode(-1);
        pre.next = head;
        ListNode ret = pre;

        while(head != null) {          
            // 找到当前翻转组的最后一个节点
            ListNode end = pre;
            for(int i = 0; i < k && end != null; i++) {
                end = end.next;
            }
            if(end == null) break;

            // 当前翻转组的第一个节点(本质上是head)
            ListNode fir = pre.next;
            // 下个翻转组的第一个节点
            ListNode nxtFir = end.next;
            // 把当前当前翻转组的最后一个节点指向pre
            end.next = pre;
            // 翻转
            reverse(fir);

            fir.next = nxtFir;
            pre = fir;
        }
        return ret.next;
    }
    public ListNode reverse(ListNode head) {
        ListNode pre = null;

        while(head != null) {
            ListNode nxt = head.next;

            head.next = pre;
            pre = head;
            head = nxt;
        }
        return pre;
    }
}
```

- **时间复杂度：O(n)**

  每一组先花 O(k) 找组尾，再 O(k) 反转，各组加起来正好把链表遍历一遍。

- **空间复杂度：O(1)**

  原地反转，只用常数个指针（哨兵 `ret`、`pre`、`end`、`fir`、`nxtFir`）。
