# 71. Decode String

- **题目 : [394. 字符串解码](https://leetcode.cn/problems/decode-string/)**

> 难度: 中等
>
> 标签: 栈, 递归, 字符串

## 解法一

```java
class Solution {
    public String decodeString(String s) {
        // 如果为空, 返回s
        if (s.isEmpty()) return s;

        // 解析当前s的s[0]是什么
        // 1. 如果s[0]是字母, 那么分离s[0], 递归后续的s[1]-s[n-1]
        // Character.isLetter()判断是否为字母 
        if (Character.isLetter(s.charAt(0))) {
            // 分离出s[0], 递归解码后续的
            return s.charAt(0) + decodeString(s.substring(1));
        }

        // 2. 如果s[0]是数字, 那么后面一定会出现括号
        // 但是, 需要注意的是, 我们要记录的是第一个左括号和对应的右括号的索引
        // 因为不止一个括号
        int start = s.indexOf('['); // 先找到第一个左括号(为什么不一定是s[1], 也许k=23呢?)
        // 用一个值去记录 (左括号 - 右括号) 的值, 以此来找到右括号
        int temp = 1;
        // 去找到最右边那个括号
        int end = start + 1;
        while (true) {
            char ch = s.charAt(end);
            if (ch == '[') {
                temp++;
            } else if (ch == ']') {
                temp--;
                // 判断temp是否为0, 如果是0, 说明找到了最左边括号对应的右括号, 开始解码
                // 1. s[0] -- s[start]是要重复的次数k
                // 2. s[start + 1] -- s[end]是要重复的内容, 继续递归解码, 得到字符串a
                // 3. s[end + 1] -- s[n - 1]是不需要重复的内容, 继续递归解码, 得到字符串b
                // 4. 我们需要把a重复k次后再加上b, 组合好了后直接返回
                if (temp == 0) {
                    // 1. 获取要重复的次数k
                    int k = Integer.parseInt(s.substring(0, start));
                    // 2. 解码得到字符串a和b
                    String a = decodeString(s.substring(start + 1, end));
                    String b = decodeString(s.substring(end + 1));
                    // 3. 组合后返回
                    StringBuilder ret = new StringBuilder();
                    // a重复k次
                    for (int i = 0; i < k; i++) ret.append(a);
                    // 加上b
                    ret.append(b);
                    // 转字符串返回
                    return ret.toString();
                }
            }

            end++;
        }

    }
}
```

- **时间复杂度：O(n² + L)**

  n 为输入长度，L 为解码后的长度。每个字符只会被处理一次，但每层递归都要 `substring` 复制一遍剩余串，纯字母的情况下会退化成 O(n²)；重复展开的拼接量对应输出长度 L。本题 n ≤ 30，实际跑得很快。

- **空间复杂度：O(n + L)**

  递归深度最多 O(n)（一路都是字母时），另外返回的结果字符串总共 O(L)。
