## 第一题 使相邻元素按位异或非零的最少删除次数

- **题目 : [Q1. 使相邻元素按位异或非零的最少删除次数](https://leetcode.cn/contest/weekly-contest-524/problems/minimum-deletions-to-make-array-sharp/)**

> 难度: 简单

### 思路

两个数异或为 0 当且仅当两个数相等，所以"相邻异或非零"翻译过来就是：**剩下的数组里相邻两个元素不能相等**。

删除元素不改变相对顺序，剩下的就是原数组的一个子序列，于是问题等价于：每一段连续相同的数字只保留一个。

一段长度为 L 的连续相同数字要删掉 L - 1 个；而这一段里"相邻且相等"的数对，正好也是 L - 1 对。所以直接遍历一遍，数有多少对相邻元素相等，就是最少删除次数，不需要真的去删。

**AC 代码：**

```java
class Solution {
    public int minDeletions(int[] nums) {
        // 本质上: 不能改变顺序的情况下, 使得相邻数不同即可
        int count = 0;
        for (int i = 0; i < nums.length - 1; i++) {
            if (nums[i] == nums[i + 1]) {
                count++;
            }
        }
        return count;
    }
}
```

- **时间复杂度：O(n)**

  只需要从头到尾扫一遍数组。

- **空间复杂度：O(1)**

  只用了 count 一个变量，没有额外开数组。

## 第二题 有向网格中的最后访问单元格

- **题目 : [Q2. 有向网格中的最后访问单元格](https://leetcode.cn/contest/weekly-contest-524/problems/last-visited-cell-in-a-directional-grid/)**

> 难度: 中等

### 思路

纯模拟。从 `(0, 0)` 出发，每一步看当前格子的字符决定往哪走；如果下一步越界，或者下一步的格子已经访问过，就停下来，最后停下的那个格子就是答案。

实现上用 `flag` 二维数组记录访问情况：每进入一个格子，先把它的坐标记到答案里，再标记已访问，最后按字符移动。

代码里把"越界"和"已访问"两个终止条件合并进了 `inArea()`，所以 `while` 循环退出的那一刻，就是走不动了。

注意：每个格子最多被进入一次，所以总步数不超过 `m × n`，不会死循环。

**AC 代码：**

```java
class Solution {
    int[] ans = new int[2];
    boolean[][] flag;

    public int[] lastVisitedCell(char[][] grid) {
        // 记录是否已经访问过
        flag = new boolean[grid.length][grid[0].length];
        motion(grid, 0, 0);
        return ans;
    }

    // 移动
    void motion(char[][] grid, int x, int y) {
        // 在范围内且没走过就一直移动
        while (inArea(grid, x, y)) {
            // 记录当前坐标
            ans[0] = x;
            ans[1] = y;
            // 开始移动
            flag[x][y] = true;
            if (grid[x][y] == 'L') y--;
            else if (grid[x][y] == 'R') y++;
            else if (grid[x][y] == 'U') x--;
            else if (grid[x][y] == 'D') x++;
        }
    }

    // 判断是否还在范围内, 且没有走过
    boolean inArea(char[][] grid, int x, int y) {
        return 0 <= x
            && x < grid.length
            && 0 <= y
            && y < grid[0].length
            && !flag[x][y];
    }
}
```

- **时间复杂度：O(m·n)**

  每个格子最多被访问一次，总步数就是格子数。

- **空间复杂度：O(m·n)**

  `flag` 数组和网格一样大。

## 第三题 找到颜色树的根

- **题目 : [Q3. 找到颜色树的根](https://leetcode.cn/contest/weekly-contest-524/problems/find-root-of-a-colored-tree/)**

> 难度: 中等

### 思路

根一旦确定，边的方向就确定了，每个深度该是什么颜色也就确定了：根是第 0 层，往下每层按 `R → B → W → R` 往后推一位。

于是两个条件分开处理：

1. **二叉树性质**：根的子节点数就是根的度，所以根的度要 ≤ 2；其余节点有一个父节点，子节点数是"度 - 1"，要 ≤ 2，也就是度 ≤ 3。题目已经保证每个点的度最多为 3，所以这里只需要筛出度 ≤ 2 的候选根。
2. **分层颜色**：把 R / B / W 映射成 0 / 1 / 2，那么深度 d 的颜色必须是 `(根的颜色编号 + d) % 3`。以候选根做一次 BFS，逐层比对颜色即可。

枚举每个候选根，BFS 全部节点都匹配就返回它；一个都不行就返回 -1。

代码里还保留了 `n == 1` 直接返回 0 的特判（本题 n ≥ 2，属于兜底）。

**AC 代码：**

```java
class Solution {
    public int findColoredRoot(int[][] edges, String colors) {
        int n = colors.length();
        // 一个节点直接返回
        if (n == 1) return 0;

        // 构建邻接表并统计度数
        List<Integer>[] adj = new List[n];
        int[] degree = new int[n];
        // 初始化邻接表
        for (int i = 0; i < n; i++) adj[i] = new ArrayList<>();
        for (int[] e : edges) {
            // 取出节点
            int u = e[0], v = e[1];
            // 加入邻接表
            adj[u].add(v);
            adj[v].add(u);
            // 度数++
            degree[u]++;
            degree[v]++;
        }

        // 存在度数 >3 的节点, 直接无解, 返回-1(无法构成二叉树)
        for (int d : degree) {
            if (d > 3) return -1;
        }

        // 把颜色转成编号, 方便计算: R--0, B--1, W--2
        int[] color = new int[n];
        for (int i = 0; i < n; i++) {
            char ch = colors.charAt(i);
            if (ch == 'R') color[i] = 0;
            else if (ch == 'B') color[i] = 1;
            else if (ch == 'W') color[i] = 2;
        }

        // 遍历候选的根(度数<=2)
        for (int i = 0; i < n; i++) {
            if (degree[i] > 2) continue;
            // bfs去层序遍历, 验证是否满足颜色分层
            if (bfs(i, adj, color, color[i])) {
                return i;
            }
        }
        // 没有满足条件的节点, 返回-1
        return -1;
    }

    boolean bfs(int root, List<Integer>[] adj, int[] color, int start) {
        // 记录节点是否访问过
        boolean[] flag = new boolean[color.length];
        Queue<Integer> q = new ArrayDeque<>();
        q.offer(root);
        flag[root] = true;
        int depth = 0;

        while (!q.isEmpty()) {
            int size = q.size();
            // 若根节点颜色对应编号start, 则深度为d的层, 预期颜色编号为(start + d) % 3
            int expected = (start + depth) % 3;

            for (int i = 0; i < size; i++) {
                int node = q.poll();
                // 颜色不匹配, 返回false
                if (color[node] != expected) return false;
                // 将相邻节点中未访问过的入队
                for (int son : adj[node]) {
                    if (!flag[son]) {
                        flag[son] = true;
                        q.offer(son);
                    }
                }
            }
            depth++;
        }
        return true;
    }
}
```

- **时间复杂度：O(n²)**

  候选根最多 n 个，每个跑一次 BFS 是 O(n)，最坏 O(n²)。不过只要某一层的颜色对不上就立刻返回 false，不用把整棵树跑完。

- **空间复杂度：O(n)**

  邻接表 O(n)，每次 BFS 新开一个 visited 数组和队列，都是 O(n)。
